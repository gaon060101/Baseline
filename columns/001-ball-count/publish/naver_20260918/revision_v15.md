# 모델 해설 15차 — 계산 순서 중심 개편

2026-09-28 · 대상: [BCAI](02_bcai.md) · [BCAP](03_bcap.md). 로컬 사용자 검토본이다.

## 적용한 요청

본문을 이미 읽은 독자가 모델의 계산 방법을 더 알아보는 글로 바꿨다. 질문→답변 구조를 없애고, 초반의 본문 표 재사용 외에는 연도별 분석 결과·순위·패턴 해석을 제거했다. 계산용 가상 예시와 계수·지원 조건은 분석 결과와 구분했다.

- BCAI: 타석 정리 → 최종 W 부여 → 도달 카운트 연결 → 시즌별 평균 → 100 기준 환산 → 본문 평균 정수표 → 불확실성 순서. Ridge·상태 평균 차이는 별도 보조 계산의 역할과 근거 링크만 남겼다.
- BCAP: 투구별 최종 W → 행동·입력 정의 → 경기 분할 → 두 결과 예측과 행동 확률 → 지원 범위 → AIPW → 평균 차이의 공통 과정을 먼저 설명했다. 이후 위치·스윙·구종을 별도 장으로 나누어 분류·입력·표본·차이 부호를 설명했다. 구종 안에서 FB/NFB와 FF/비포심을 구별했다.
- 본문 표: BCAI 4×3 정수표, 위치 4×3 표, 스윙 표, 구종 표를 재사용했다. 표의 값·기간·분모·해석 조건을 유지했다.
- 결과 그림은 해설에서 제외했다. BCAP 다섯 구역 도식만 분류 설명 위치에 유지했다.

## 보존과 근거

수정 전 두 해설과 본문·문헌·검증 원고의 MD/HTML 및 발행 README는 [보관 폴더](revisions/v14_before_models_v15/)에 남겼다. [수정 전 해시](revisions/v14_before_models_v15/hashes.json). 제거한 결과 서술·세부 표는 보관본과 원래 분석 보고서에서 확인할 수 있다.

모델 명세와 `models/bcap/r/engine.R`의 실제 점수·지원·집계 계산을 대조했다. 새 데이터 수집·통계 계산·모델 변경·상태 승격은 하지 않았다. 본문 01과 문헌 04·검증 05의 MD/HTML은 작업 전 해시와 일치한다.

## 검수

- [HTML 생성 검사](models_v15/render_check.json): 두 해설만 생성, 로컬 파일 링크 확인.
- [화면 검사](models_v15/visual_check.json): Edge 1280·390·360px의 6화면에서 가로 넘침·표 셀 넘침·이미지·로컬 링크·앵커·강조 표시 확인. 모바일 BCAI 표, BCAP 계산 설명과 PC 스윙 표의 저장 화면도 직접 확인했다.

미리보기 생성은 `build_models_v15.mjs`, 내용 검사는 `verify_models_v15.py`, 화면 검사는 `check_models_v15.mjs`를 사용한다. `revise_models_v15.py`는 보관을 수반한 일회성 편집 기록이므로 재실행하지 않는다.
