## 이번 작성 중 외부 원문 확인

- **FanGraphs, wOBA, Piper Slowinski, 2010-02-15:** <https://library.fangraphs.com/offense/woba/>. 2026-09-18 웹 원문 열람. 작성자 본문의 도입·Calculation·Why wOBA·How to Use·Context·Things to Remember까지 읽었다. 실제 사용 범위는 결과별 가중치와 시즌별 계수, 공식 분모 설명이다. 댓글은 근거로 사용하지 않았다.
- 공식 시즌 계수표 <https://www.fangraphs.com/tools/guts?type=cn> 및 구 주소 <https://www.fangraphs.com/guts.aspx?type=cn>는 이번 웹 열람에서 내부 오류를 반환했다. 따라서 **이번에 원표까지 재확인했다고 주장하지 않는다.** 원고 표1의 정확한 숫자는 이미 보존된 자체 실행·보고서에 실제 사용한 계수로 제시했다.
- **외부 논문·외부 연구의 실증 결과는 이 동반 해설에서 인용하지 않았다.** BCAI의 자체 수치와 방법을 설명했다. Stotz/Bickel 등 논문명을 원문 확인 없이 붙이지 않았다. 종료 카운트 설명은 지표의 분모를 직접 풀어 설명한 부분이다.

## 모의 예시와 실제 결과

- `0-0→0-1→0-2→1-2→일반 파울→2-2→홈런`은 집계 정의를 설명하기 위한 명시적 가상 타석이다. 실제 경기·선수 사례로 묘사하지 않았다.
- 해당 예시에 적용한 2024 홈런 계수2.050은 실제 저장 계수다. 예시 결과를 실측 통계로 사용하지 않았다.
- 본문에 없는 새 상대 반응·분해 값, KBO 결과, 최적 전략 수치를 만들지 않았다.

## 편집 시 유지할 점

- 모델명은 저장소와 일치하는 BCAI다. 사용자 표현 BACI는 원고에서 별도 지표처럼 만들지 않았다.
- 본문4개 표: W계수, 12카운트, 모델역할, 상태차이. 모바일을 고려해 모두4열 이하.
- 내부 형제 글 링크 `01_ball_count.md`, `03_bcap.md`는 주 작업이 만들 파일 기준이다. 실제 블로그 업로드 전 글 URL로 교체해야 한다.
- 원고 하단의 근거 MD·CSV 링크는 로컬 검토 패키지 링크다. 공개본에는 사용자 공개 자료 링크가 있는 경우 그 링크로 대체하거나 독자에게 자료 안내만 남긴다. 미발행 URL을 만들지 않는다.
- 작성자의 진술은 분석의 실제 정의·작업 기록 범위다. 확인하지 않은 대화의 감정·발언·인용을 만들지 않았다.
