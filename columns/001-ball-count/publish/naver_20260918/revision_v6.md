# 본문 6차 — 질문을 따라 읽는 설명 복원

사용자의 “기존의 질문을 던지면서 설명하는 구조는 좋았어 그거 살리면서 다시 작성해줘”를 반영했다.

- 다섯 장의 도입을 야구 상황에서 출발하는 질문으로 썼다. 장별 읽기 안내도 독자가 차례로 풀 질문을 보여주도록 바꿨다.
- 세부 풀이 17개를 질문형 소제목으로 구성했다. 질문 바로 뒤에 핵심 답을 제시하고, 숫자·예시·문헌으로 설명을 이어간다.
- BCAI의 1-1, 존 밖과 버리는 공, 3-0의 스윙 빈도, 구종 비교의 불명확함은 첫 답과 연결 문장도 다시 썼다. 제목만 바꾼 수정이 아니다.
- 5차의 간단 설명 → 결과 한눈에 보기 → 상세 설명 위계와 표 6개·그림 5개는 유지했다. 질문 때문에 결과를 다시 뒤로 미루지 않았다.
- `01_ball_count.md`·HTML·허브 버전 안내를 갱신했다. `guides/writing.md`에 질문과 두괄식을 함께 적용하는 원칙을 기록하고, 루트/발행 README·column.md의 현재 상태를 맞췄다.

이전 원고와 렌더러는 `revisions/v5_before_question_v6/`에 보존했다. 02–05 원고·분석·데이터·그림 PNG는 편집하지 않았다. 기존 ZIP은 4차 자료다. 새 문헌을 인용하거나 외부 게시·업로드하지 않았다.

`revision_v6_check.json`에서 표·그림·외부 링크 보존과 질문형 세부 제목 17개를 확인했다. HTML 화면·앵커 확인은 `visual_check.json`에 기록한다.
