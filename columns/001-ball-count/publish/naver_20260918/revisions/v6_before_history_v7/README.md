## 최신 상태 — 본문 6차 질문형 설명

[01 본문 MD](01_ball_count.md) · [HTML](01_ball_count.html)의 질문을 던지며 풀어가는 문체를 복원했다. 장별 도입 질문과 세부 질문 17개 뒤에 짧은 답·예시·근거를 연결했다. 5차의 3단계 목차·표 6개·그림 5개는 유지한다. [6차 기록](revision_v6.md). 아래 5차 설명은 이력이며, 02–05 원고·기존 ZIP은 4차 상태다.

## 최신 상태 — 본문 5차 구조 개편

[01 본문 MD](01_ball_count.md)와 [HTML](01_ball_count.html)은 주제별 `간단 설명 → 결과 한눈에 보기 → 상세 설명`으로 다시 구성했다. 결과 표 5개와 분모 예시 표 1개를 새로 만들었다. [수정 기록](revision_v5.md). 02–05 원고는 4차를 유지한다.

본문의 그림 3은 스윙 결과(`05_swing_2023.png`), 그림 4는 구역 도식(`04_zone_map.png`)으로 순서가 바뀌었다. 그 외 그림은 동일하다. 아래 공유 ZIP·배치 안내는 **이전 4차 자료**이며 최신 본문을 포함하지 않는다. 현재 검토에는 위 MD·HTML을 사용한다. `restructure_v5.py`는 일회성 편집 기록으로 재실행하지 않는다.

### 공유와 네이버 이전

새 검토용 묶음 `볼카운트_5편_검토본_20260927.zip`은 압축을 모두 풀고 `index.html`을 열어 읽는다. HTML·원고·그림을 같은 묶음에 넣고 프로젝트 바깥 파일에 의존하는 링크를 제외해 다른 폴더에서도 읽을 수 있게 한다. 해당 링크의 근거는 원본 프로젝트 MD에 보존한다. 기존 첨부 그림 ZIP은 보존하고 현재 배치를 반영한 `네이버_첨부그림_8장_v4.zip`을 별도로 만든다.

네이버용으로는 MD 내용·표와 PNG를 옮기고, 해석 메모·문헌·용어주 제목을 유지한다. HTML 스타일이나 각주 점프가 그대로 보존된다고 가정하지 않는다. 공개 주소 미확정인 글 간 링크는 편집 단계에서 실제 주소로 교체한다. 실제 원격 공유 링크의 Not Found 원인은 아직 확인하지 않았고 서버를 수정하지 않았다.

원고 편집은 중단 상태다. 상세 상태·재개 조건은 [칼럼 현재 상태](../../column.md#current-status)를 따른다. 01–04 MD와 HTML은 보존되어 있고, [05 데이터·검증 글](05_data_validation.md)은 MD 초안만 있다. 05 HTML과 기존 `index.html`의 05 연결은 없으며 이번 정리에서 생성하지 않았다. 본문 축약이나 내용 이관도 수행하지 않았다.

아래 9월 19일 기록의 ‘미작성’은 당시 안내이며 현재 파일 존재와 다르다. 이전 기록과 원고는 그대로 보존한다. 아래의 수정·게시 절차는 편집 재개나 외부 업로드를 허가하는 지시가 아니다.

## 현재 읽기 대상: 3차 수정본

**결과를 먼저 읽고 계산과 이유를 뒤에서 확인하는 두괄식**으로 고쳤다. 아래의 2차 기록은 이전 수정 이력이다. 최신 기준은 [3차 수정 기록](revision_v3.md)이며 공통 원칙은 [집필 지침](../../../../guides/writing.md)에 저장했다.

청록색 결과 요약, 갈색 해석 메모, 보라색 참고문헌, 초록색 실제 인용 부분을 구분한다. 큰 번호 제목과 작은 번호 제목은 상하 관계를 표시한다. 네이버로 옮길 때도 색상뿐 아니라 상자 제목과 제목 단계를 함께 유지한다.

BCAP의 결과는 첫 절에 모았다. BCAI는 전체 카운트 결과와 보조 결과가 계산 설명보다 앞에 있다. 본문은 모델 역할과 결과 네 가지를 먼저 제시한다. 기존 결과표는 보존했고 요약표를 추가했다. 현재 표 수는 `render_check.json`을 기준으로 한다.

2차 원고는 `revisions/v2/`에 보관했다. 과거 HTML은 보관본이므로 실제 읽기에는 현재 폴더의 HTML을 사용한다.

작성 기준일: 2026-09-18. 한 칼럼의 본문과 두 방법 해설을 묶은 원고다. 새 칼럼 번호를 만들지 않았다. 외부 게시·Google Docs 수정·드라이브 업로드는 수행하지 않았다.

## 2차 수정본 — 설명 확장과 문헌 해설

기존 구조·문체를 유지하면서 결과 앞의 질문·비교·그림 읽기를 보강했다. 통계·해석상 주의점은 **해석 메모** 상자로 분리했다. HTML에서는 갈색 배경과 바탕 계열 글꼴이며, 문헌의 실제 인용 부분은 초록 상자다. [수정 기록](revision_v2.md).

네이버에 옮길 때도 `해석 메모`라는 제목을 남기고 인용구 또는 배경색 상자로 구분한다. 글꼴만 바꾸는 것보다 제목·테두리·색을 함께 유지하는 편이 구별하기 쉽다. HTML의 스타일이 네이버에 자동 보존된다고 전제하지 않는다.

## 블로그에 옮길 때의 연결

사용자 검토 후 네이버 편집기에 본문과 표를 옮기고, 지정된 위치에 PNG를 별도로 첨부한다. HTML 파일 자체를 네이버가 그대로 불러온다는 전제로 만들지는 않았다.

실제 게시 주소가 생기면 1편에서 2·3편으로, 두 설명 글에서 1편으로 가는 링크를 그 주소로 바꾼다. 문헌 해설을 게시하면 본문의 문헌별 연결도 해당 공개 주소로 바꾼다. 현재는 로컬 파일 링크다. 내부 분석 보고서·CSV·명세 링크도 로컬 검토용이다. 게시할 때는 공개하기로 한 자료의 주소로 바꾸거나 서지·자료명 표기로 남긴다. 존재하지 않는 공개 주소를 미리 만들지 않았다. 논문·외부 분석 글의 원문 링크는 실제 URL이다.
