## 집필 중 검토와 수정

- 숫자는 원 CSV와 대조했다. 그림 05의 지원·구간 분류는 스윙 방향 10셀, 테이크 방향 44셀, 불명확 2셀, 자료 부족 4셀과 일치했다.
- 기존 분석을 이해하기 위한 상태 차이를 실제 볼 허용 효과로 읽지 않도록 제목·본문을 수정했다. 그림 07은 세 개의 비종료 상태 평균 비교만 남겼다.
- 초기 렌더에서 한글 글꼴이 빼기기호를 빈 네모로 표시해 그림에서는 ASCII 빼기기호로 바꿨다. 0-0 기준 칸도 중립 색으로 구분했다.
- 2023 자료의 이전 노출 이력·외부 연도 내부 재적합, 그림의 구간 보정 범위를 명시했다.
- 실제로 측정하지 않은 ‘원인별 기여’를 암시하지 않도록 ‘사건별 가치 기여’로 썼다.
- 전문 미확인 자료는 제외했고, 원문 내부 수치 불일치가 있던 문헌의 해당 숫자는 쓰지 않았다. 확인한 버전과 원문 이미지 접근 한계를 기록했다.
- HTML의 본문·방법 글 상호 링크와 그림 로딩, 1280px·390px 화면에서 페이지 가로 넘침을 확인했다. 표는 필요한 경우 표 영역 안에서 스크롤한다.

사용자 내용 검토, 실제 네이버 편집기에 옮긴 뒤의 표시 확인, 게시 URL로 내부 링크 교체와 외부 발행은 별도다. 현재 글은 완성 초안이며 게시 완료 상태가 아니다. 모델 학습·새 데이터 확보·KBO 분석·Drive 업로드는 이번 집필 범위에 포함하지 않았다.
