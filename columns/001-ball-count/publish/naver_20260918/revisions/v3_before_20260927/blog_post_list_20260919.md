# 볼카운트 연재 — 함께 게시할 글 추천 목록

작성일: 2026-09-19. 현재 세 원고와 한국어 문헌 해설의 참고 링크를 기준으로 정리했다. 게시 목록 제안이며 새 원고 집필·외부 게시를 완료했다는 뜻은 아니다.

**기존 세 글에 두 편을 더해 총 다섯 편으로 묶는 것을 권한다.** 추가 두 편 가운데 문헌 해설은 이미 초안이 있고, 데이터·검증 안내만 독자용으로 새로 정리하면 된다. 독자가 다섯 편을 모두 선행 학습해야 하는 구성은 아니다. 본문에서 필요한 순간에 참고하는 방식이다.

## 2. 추가 4 — 한국어 참고문헌 해설

**이미 본문이 여러 외부 연구를 인용하므로, 이 해설은 함께 게시하는 편이 좋다.** 영어 원문 링크만으로는 연구의 결론과 이번 칼럼에 가져온 부분을 독자가 확인하기 어렵다.

기존 해설의 결과·결론 우선 구성, 초록색 인용 부분, 보라색 원문 정보, 갈색 해석 메모를 유지한다. 모든 논문을 별도의 블로그 글로 쪼개기보다 문헌별 목차가 있는 한 편을 우선 권한다.

- 먼저 보여줄 것: 문헌별 핵심 결론과 이번 칼럼에서 사용한 부분.
- 이어 설명할 것: 자료·분모·방법·한계와 이해를 돕는 예시.
- 연결할 곳: 본문 보라색 참고문헌 상자에서 해당 연구의 해설로 연결. 네이버에서 문헌별 바로 이동을 지원하지 않으면 해설 글 링크와 문헌 번호·제목을 함께 표시.
- 게시 전 정리할 것: 내부 `reference_audit.md` 링크는 독자가 읽을 수 있는 ‘읽은 판본과 사용 범위’ 설명으로 바꾸고, 원문 주소는 유지.

이 글의 목적은 외부 연구를 읽는 것이다. 우리 분석의 검증 결과는 다음 데이터·검증 글에서 다룬다.

## 3. 추가 5 — 데이터와 검증 기록

**현재 원고에 흩어진 내부 보고서 중 독자에게 가장 필요한 내용은 ‘자료의 범위와 결과를 확인한 범위’다.** 이를 한 편으로 묶으면 출처를 따라갈 때 갑자기 기술 문서나 검수 기록을 만나지 않아도 된다.

### 글 첫머리에 보여줄 결과

기간·수행한 분석·확인한 내용·미확인 내용을 표로 정리한다. 2024·2025 개발 분석, 2023년 확인, 2026년 부분 시즌의 구종 비교와 위치 보류를 구분한다. OBS·Ridge·BCAP의 검증 상태도 각각 설명한다.

### 뒤에서 풀어 쓸 내용

1. **어떤 데이터를 썼나:** 리그·시즌·확보 기준일과 출처. 타석과 투구를 별도로 세는 이유.
2. **무엇을 제외했나:** 고의볼넷·미완료·최종 결과 결측·타격방해 처리. 최종 결과가 없는 기록을 아웃으로 채우지 않은 이유.
3. **결과를 어떻게 확인했나:** 저장 값의 산술 검산, OBS 구간 계산, Ridge 수렴·예측 평가, BCAP의 다른 연도 패턴 확인을 구별.
4. **무엇을 고쳤나:** 분모 혼용, Ridge 초기 수렴, 2026년 누락 경기 보충, 구종 분류를 다시 나눈 과정. 해결한 문제와 남은 문제를 따로 표시.
5. **무엇을 아직 말할 수 없나:** 2026년 위치의 측정 기준 문제, 실제 사건별 기여도 미산출, 상대 적응·최적 배합 미산출, KBO 미검증.

각 소주제도 결론을 먼저 제시하고 사례와 근거를 뒤에 붙인다. 독자의 이해에 필요한 검증 사실을 설명하며, 실행 명령이나 파일 목록을 본문 중심으로 삼지 않는다.

### 기존 글과의 역할 분담

- BCAI·BCAP에는 결과를 읽는 데 꼭 필요한 정의와 짧은 해석 메모를 남긴다.
- 데이터·검증 글에는 자료 처리와 확인 절차의 상세 근거를 모은다.
- 본문에는 분석 기간과 핵심 범위만 짧게 적고 이 글을 연결한다.
- 원본 데이터·모델 파일의 공개나 배포는 별도 사항이다. 블로그 설명 글을 올린다고 해당 파일을 함께 공개하는 것은 아니다.

## 5. 당장 별도 글로 늘리지 않을 내용

**wOBA 기초, 신뢰구간·보정 입문, 상태와 행동의 차이는 우선 기존 해설 안에서 해결하는 편이 낫다.** 이를 모두 새 글로 분리하면 결과를 이해하려고 링크를 계속 옮겨 다녀야 한다. 초보 독자의 반복 질문이 확인되면 그때 독립적인 입문 글로 확장할 수 있다.

상대 적응·최적 배합·KBO 검증을 ‘완료된 분석 글’ 목록에 넣지도 않는다. 현재 미완료 범위이므로 후속 연구 주제로 남긴다.

**권장 구성은 본문 1편 + 모델 해설 2편 + 문헌 해설 1편 + 데이터·검증 안내 1편이다.** 실제 게시 준비는 보조 글의 공개 주소를 확보한 뒤 본문의 참고 연결을 맞추면 된다. 여기서는 목록만 정리했으며 현재 원고의 링크 교체나 새 원고 작성은 수행하지 않았다.
