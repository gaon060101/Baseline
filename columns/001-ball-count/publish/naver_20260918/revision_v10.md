# 본문 10차 수정 기록

2026-09-28. 사용자 피드백 6개 반영. 본문 MD·HTML과 본문용 렌더/검수 자료를 수정했으며 해설 02–05 및 index는 유지했다.

## 반영 내용

- BCAI 표는 2015–2025 연도별 점수 11개를 동일 비중으로 평균 낸 후 정수로 반올림했다. 타석을 모두 합친 통합 지수와 구별했다. R 계산 `prepare_main_v10.R`, 산출물 `main_v10/bcai_means.csv`.
- 질문마다 다시 시작되던 숫자를 없앴다. 기존 장 구조를 유지하고 ‘위치 결과 읽기’, ‘구종 결과 읽기’, ‘비슷한 점수와 다른 통계’, ‘스윙 비율과 스윙의 질’, ‘한 번의 결과를 넘어’라는 중간 제목을 넣었다.
- 스윙 분석의 중심을 두 스트라이크에서 존 밖까지 방어해야 하는가로 구체화했다. 0-2의 존 밖 44개, 두 스트라이크 전체 176개 비교의 방향을 확인하고 2023년 0-2 스윙/지켜보기의 보정값·차이·분모·구간을 예시로 추가했다.
- 위치와 구종에도 연도별 W 차이 범위를 제시했다. W는 득점·승률·BCAI 점수와 다른 단위임을 결과 옆에 설명했다.
- 본문 문헌 1·4·5·6·7·8 각각의 질문·자료·비교 방법·주요 결과를 풀었다. 외부 연구와 자체 분석의 기간·단위를 구별하고 밑줄과 바로 아래 출처 서식을 유지했다.
- 마지막 장을 카운트 변화, 타자의 대응, 경기 장면, 최종 결론의 네 소제목으로 확장했다. 63→71→85→119는 서로 다른 카운트 집단의 평균이며 볼 하나의 인과효과나 경로 계산이 아님을 명시했다.

## 문헌 확인 범위

Ciardiello 원문에서 2019–2020 결과 비율(존 밖 볼 56.8%, 헛스윙 12.7% 대 9.5%, 타구 7.7% 대 27.1%)을 재확인했다. Turkenkopf 1편은 2008년 38,606개 중 4,297개와 위치 기준의 정의를 확인했다. Gentile은 2010–2013 경계 공의 두 스트라이크 스윙률, Weinberg는 3-0·3-1의 스윙률과 패스트볼 비중을 확인했다. Yee·Deshpande는 실제 Smith 홈런 사례의 기대 득점 이득 약 0.01점과 90% 구간을 확인했다.

Stotz·Bickel 원문 재접속은 내부 오류로 실패했다. 이 대화의 앞선 본문 편집에서 읽은 원문 내용과 자료 범위에 한정해 설명을 확장했고, 문제가 기록된 별도 해설의 숫자는 옮기지 않았다. 새로 재열람한 것으로 보고하지 않는다. 해설 04의 기존 수치 정정은 이번 범위에 포함하지 않았다.
