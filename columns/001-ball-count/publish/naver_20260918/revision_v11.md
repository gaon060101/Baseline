# 본문 11차 수정 기록

2026-09-28. 사용자 피드백 6개를 반영했다.

- W의 정의와 최종 타석 결과→점수→평균 계산을 BCAI보다 먼저 설명했다. BCAI는 평균의 비율×100, BCAP는 같은 카운트에서 두 집단의 보정 평균 비교라는 역할을 결과 전에 소개했다.
- 본문에서 위치·구종의 W 차이 범위와 2023년 스윙의 소수 점수표를 덜었다. 사용자가 상세 설명으로 보내도록 요청한 내용은 `03_bcap.md#main-numeric-examples`에 추가했다. 원래 상세 설명은 유지했다.
- 스윙 절을 ‘두 스트라이크면 존 밖까지 방어해야 하는가’라는 질문과 최종 타석 결과의 의미로 다시 풀었다. 두 스트라이크 네 카운트 결과표를 제시하고, 삼진 회피와 출루·장타까지 포함한 타석 성과를 구별했다.
- 132개를 ‘12카운트를 매년 따로 비교한 132번’으로 설명하고, ‘2019년 0-2 존 안’ 한 건의 예를 들었다. 존 밖 481·528개 등의 횟수와 불확실성 수치는 상세 설명으로 옮겼다.
- BCAI 정수 표와 참고문헌 상자는 그대로 보존했다. 해설 02·04·05와 index도 해시가 같다.
- 수정 전 본문·BCAP 설명·HTML·렌더러는 `revisions/v10_before_accessible_v11/`에 보존했다.

검증: `main_v11/content_check.json`, `main_v11/visual_check.json`. 본문과 BCAP 상세 설명을 Edge 1280·390·360px에서 확인했으며 로컬 링크·앵커·이미지·표·가로 넘침 검사 통과. 모바일 스윙 표 시각 확인. 원자료나 모델 재적합 없이 기존 결과를 재서술했다. 외부 게시·업로드 없음.

생성: 본문은 `build_preview.mjs --only-main`, BCAP는 `--only-bcap`. 다음 단계는 사용자 원고 검토다.
