# 모델 해설 16차 — 다섯 발행 글 안에서 계산 설명 완결

2026-09-28 · [BCAI MD](02_bcai.md) · [BCAP MD](03_bcap.md) · [BCAI HTML](02_bcai.html) · [BCAP HTML](03_bcap.html).

## 반영 내용

- BCAI 1–6절의 승인된 서술·계산 흐름과 표를 유지했다. 필수 내용을 별도 문서에서 읽도록 하던 연결 문구만 정리했다.
- 7절은 복원추출 예시, 재표본별 재계산, 2,000회 분포와 개별 구간, 근사 동시 구간, 쌍 차이 구간을 나누어 보강했다.
- 8절에 Ridge의 입력·학습 정규화·규제·중첩 경기 분할·잔차·100 기준 보조 지수 계산을, 9절에 STATE-DELTA의 상태값·종료값·간격·분모·파울과 예외 처리를 추가했다. 가상 예시이며 새 분석 결과가 아니다.
- BCAP는 1부 공통 계산, 2부 위치, 3부 스윙, 4부 구종으로 구분했다. 결과표 3개는 해당 분류 안으로 옮겼다.
- BCAP 자체 W 계수표·처리 기준, Platt 확률 보정, 두 행동의 AIPW 예시, 같은 투구에서 평균내는 예시, ESS와 경기 군집 구간 계산을 보강했다. 각 분류에도 실제 행동 이름을 넣어 계산 과정을 풀었다.
- 발행 대상 다섯 글 밖의 내부 명세·기술 보고서는 독자용 이동 경로에서 제외하고 두 해설의 집필 근거표에 보존했다. 필수 계산을 글 안에 썼으며 외부 논문을 새로 인용하지 않았다.
