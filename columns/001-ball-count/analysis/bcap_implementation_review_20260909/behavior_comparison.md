# 실제 행동과 학습 후보의 행동 비율 비교

작성 시각: 2026-09-09T08:34:45.326189+00:00. 기존 완료 실행의 보조 CSV를 표로 옮긴 **봉인 후 표시 전용 자료**다. 새로운 효과 추정·정책 학습·등급 변경은 하지 않았다. 행동 추천은 없다.

행동1은 PITCH에서 FB(FF/SI/FC), SWING에서 번트를 포함한 기록상 Swing이다. 각 행의 실제 비율과 후보 비율은 **동일한 공통 지지 의사결정 행**에서 계산된 저장값이다. PA와 경기도 이 지지 집단의 고유 개수다. “공통 지지/전체 적격 행”은 비율 계산에 사용한 행 수와 지지 적용 전 적격 행 수를 함께 표시한다. 원 주 보고서의 전체 적격 행 실제 비율과 분모가 다를 수 있다.

차이는 후보 비율−실제 비율의 퍼센트포인트(%p)다. 예상 불일치율은 후보가 같은 평가 행에서 실제 관찰 행동과 다른 행동을 선택할 확률의 평균이다. 실제로 바꾸도록 권하는 투구의 비율이 아니며, 행동 비율 차이나 불일치율은 공격가치 개선량이 아니다. 확률 후보도 이 정의로 읽는다.

개발 표는 각 outer 훈련 부분 안에서 학습한 후보를 해당 outer 평가 경기에서 비교한 **학습 절차의 평가**다. 개발 전체로 마지막에 학습해 고정한 정책의 행동 비율로 읽으면 안 된다. 외부 표는 그 마지막 개발 정책을 고정하고 외부 경기 교차 적합 nuisance의 공통 지지 행에서 비교했다. 고정 개발 nuisance만 적용한 별도 예측 진단의 행은 포함하지 않았다.

모든 표에서 보수 정책은 관찰 행동 메커니즘을 유지한다. 따라서 보수 정책의 기대 행동1 비율은 같은 행의 실제 비율과 같고 예상 불일치율은 0이다. 이 동일성은 정책 정의의 결과이며 효과 검증이 아니다.

## 보류와 읽기 범위

2026 SWING은 위치 기준면·존 정의의 정합성이 확보되지 않아 전체 평가를 보류했다. 해당 행동 비율 비교를 만들지 않았다. 개발·외부 표의 실제 선수·상황·공통 지지 분포도 서로 같지 않으므로 연도 사이 비율 차이를 정책 변화의 효과로 해석하지 않는다.

결과는 현재 한 구에 대한 후보 정책의 기술적 비교다. 선수별 실행 가능한 구종·구종 품질·의도·타자 지각·미측정 교란과 완료 PA 선택 문제는 남는다. 이 표로 추천 등급을 올리거나 모든 투구에 적용한 PA 전체 개선량을 계산하지 않는다.
