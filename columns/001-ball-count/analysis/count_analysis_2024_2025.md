# 2024·2025 MLB 통합 볼카운트 분석

## 분석 범위

2024년과 2025년 MLB 정규시즌을 하나의 표본으로 합쳤다. 원본 1,424,427행, 실제 구종이 확인되는 1,419,135투구, 4,859경기, 366,231타석이다. 원본은 연도별 폴더에 그대로 보존하고, 정제 결과만 통합했다.

카운트는 투구 전 상태다. 자동 볼·자동 스트라이크와 구종 결측은 투수의 구종 선택에서 제외했으며, 자동 판정은 다음 공 결과표에 별도 보존했다. 타석 최종 결과는 같은 타석이 한 카운트에 여러 번 머물러도 한 번만 집계했다.

## 중심 해석

1. **초반 스트라이크 선점의 가치:** 0-2 도달 타석의 삼진율 45.86%와 2-0 도달 타석의 14.13%는 카운트 우위가 최종 결과와 강하게 연결됨을 보여준다.
2. **유리한 카운트에서의 유인구:** 0-2 다음 공의 볼 비율이 45.90%라는 결과는 투수가 즉시 스트라이크를 넣기보다 타자의 추격 스윙을 유도한다는 설명과 맞는다.
3. **3볼 카운트의 차이:** 3-0과 3-2의 스윙률은 9.07%와 70.49%다. 볼 수만 같아도 스트라이크 수가 타자의 선택을 크게 바꾼다.
4. **포심의 역할:** 3-0에서는 포심 비중이 64.99%로 높아져 투수들이 스트라이크 확보에 주로 빠른 공을 사용한다.

이 수치는 해당 카운트에 도달한 집단의 관찰 결과다. 카운트가 결과를 단독으로 유발했다는 뜻은 아니며, 구종별 단순 성과 순위도 투수·타자 수준과 로케이션을 통제하기 전에는 최적 선택으로 해석하지 않는다.
