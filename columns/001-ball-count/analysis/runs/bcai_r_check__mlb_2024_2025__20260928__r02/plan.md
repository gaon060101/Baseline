# R 연결 및 BCAI 재계산·연도 비교 계획

작성일: 2026-09-28. **2024·2025 실행 승인·계산 전 계획 확정**. 연결만 요청했던 보류 이후 사용자가 “일단 2024 2025 R로 돌려보고 다른 연도에 적용가능한 분석 코드 만들어봐”라고 명시적으로 재개했다. 이번 실제 실행은 2024·2025이며 다른 연도는 적용 가능한 코드와 설정 방법만 준비한다.

향후 요청 범위는 2024·2025 재계산 후 2015~2025 확장 및 2026 보조 비교다. 아래는 첫 단계만의 계획이며, 확장 단계에는 연도별 자료·가중치·제공 조건·2026 기준일 확인이 별도로 필요하다.

- 질문: 기존 BCAI 관찰 지수가 R에서도 재현되는가? 2025−2024의 카운트별 상대 지수 차이는 얼마나 불확실한가?
- 기존 시즌별 결과에 이미 노출된 후속 탐색이다. 신규 외부 검증·사전 등록 가설 검정으로 부르지 않는다.
- 정의: BCAI-OBS-v1.0.0의 결과 분류·제외·시즌 가중치·시즌 내 0-0 정규화를 그대로 적용한다. 도달한 타석은 카운트별 한 번만 센다.
- 입력: 기존 advantage_input_cache.pkl의 8개 필드. Python은 R에서 읽기 위한 CSV 형식 변환만 수행하며 집계·모형 계산은 R에서 한다. 캐시 이전 원본 처리의 독립 검증은 아니다.
- 필드: game_pk, at_bat_number, pitch_number, game_year, game_date, balls, strikes, events. R에서 키·순서·카운트·시즌을 검사하고 보존된 연도별 정규시즌 일정과 경기 집합을 대조한다.
- 확인: 기존 전체/유효 타석 수, 제외 집계, 카운트별 표본 수, 시즌별 평균·지수와 혼합 지수 대조. 지수 허용 오차 1e-9.
- 추가 계산: 연도별 경기 단위 복원추출 2,000회, seed 20260928. 매회 기준 평균을 다시 계산한다. 연도별 추출은 독립이며 같은 연도 안의 모든 카운트는 같은 경기 추출을 공유한다.
- 연도 차이: 2025 지수−2024 지수, 단위는 지수 포인트. 11개 비기준 카운트 전체를 보고한다. 점별 95% 구간과 최대 표준화 편차 방식의 근사 동시 95% 구간을 구별한다. 0-0은 정의상 차이 0이다. 유의하지 않음을 동일함의 증거로 쓰지 않는다.
- 가중치 추정 오차·동일 선수의 경기 간/연도 간 의존성은 반영하지 않는다. 인과 효과·미래 예측·정책 추천·KBO 검증으로 해석하지 않는다. 실질적 동등성 한계는 정하지 않았으므로 동등성 검정은 하지 않는다.
- 산출물: CSV 결과, 검산 JSON, 실행 manifest·환경·입출력 해시, 한국어 보고서, 블로그용 PNG 두 장. 기존 발행 원고에는 자동 삽입하지 않는다.
- 기존 모델 상태와 과거 실행은 유지한다. 이번 점추정 재현이 기존 모든 CI·Ridge·BCAP 검증을 뜻하지 않는다.
- 원형 OBS의 혼합 지수와 새 연도 차이의 불확실성은 별도 보고한다. 난수 생성기가 다른 Python과 R의 구간 끝점 일치는 요구하지 않는다. 다른 연도로 확장할 때 모든 지정 연도 쌍×비기준 카운트를 하나의 동시 구간 집합으로 계산한다.
- 새 R 구현의 작은 모의 예제로 제외 순서·마지막 이벤트 결측·반복 카운트·입력 순서·중복 키 거부·다른 연도 적용·부트스트랩 재현성을 확인한 뒤 실제 자료를 실행한다.


r01은 반복 카운트 제거 감사의 분모를 유효 PA로 한정해 기존 전체 행 감사와 불일치하여 중단했다. 지수·카운트 표본 대조는 통과했고 부트스트랩은 실행 전이었다. 감사 분모를 원 정의와 맞춘 뒤 새 r02에서 재실행한다. r01은 FAILED로 보존한다.
