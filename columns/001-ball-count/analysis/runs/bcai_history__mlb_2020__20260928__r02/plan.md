# 2020 BCAI 일정 완료 상태 수정 후 재실행

2020 r01은 일정 기준 900경기와 입력 898경기의 불일치로 중단됐다. 원인은 입력 손실이 아니라 저장 일정의 `abstractGameState=Final`만으로 연기 기록까지 완료 경기로 고른 데 있다. gamePk 631471·631472는 같은 일정 파일에 `Postponed(D/D9)`와 `Cancelled(C/C9)` 기록이 모두 있었고, 실제 완료 기록은 없었다.

완료 기준을 정규시즌(`R`), `abstractGameState=Final`, `codedGameState=F`, `detailedState`가 `Final` 또는 `Completed Early`인 기록으로 한정한다. 조기 종료된 실제 경기는 포함하고, 연기·취소·중단·알 수 없는 상태는 포함하지 않는다. 동일 경기의 과거 일정 기록이 반복될 수 있으므로 경기 ID를 중복 제거한다.

2020~2025 저장 일정과 작은 상태 회귀 확인은 [실제 필터 확인 코드](check_schedule_filter.R)·[확인 결과](schedule_check.json)를 따른다. 2020만 900→898경기로 바뀌고 2021~2025의 고유 완료 경기 수는 유지되는지 확인한다. 입력 CSV의 실제 경기 ID 집합도 완료 집합과 대조한다.

기존 원본·정제 입력·가중치·seed·2,000회 경기 부트스트랩·추정 함수 `bcai.R`를 유지한다. r01의 실패 기록은 보존하고 새 ID r02로 실행한다. 모델의 정의나 검증 상태를 승격하지 않는다. 실행 완료 후 별도 보고서를 작성하고 과거 결과 허브만 갱신한다.
