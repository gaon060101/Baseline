# BCAP 투수·타자 결과와 검수 안내

작성: 2026-09-14. 기존 2024·2025 개발 결과를 읽기 쉽게 재구성했다. 모델 수정·재학습·외부 검증·독립 수치 검산을 실행하지 않았다.

- [보고서 미리보기](report.html): 투수 실제 S/B 12카운트, FB/NFB와 FF/non-FF 공통 표본 비교, 타자 카운트 평균 및 5구역 60셀, W 해설과 검수 순서.
- [입력 해시와 출력 기록](report_manifest.json)
- [보고서 생성 코드](build_report.py): Python 표준 라이브러리만 사용. 기존 CSV를 읽어 표시하며 추정량을 다시 학습하거나 판정을 변경하지 않는다.
- [최신 모델 인계](../handoff_bcap_review.md)

## 결과를 읽을 때

투수 실제 S/B는 0-2·1-2에서 B의 허용 공격가치가 약0.02~0.03 W 낮다. 0-1은 불명확하고 나머지9카운트는 S 방향이 뚜렷하다. S/B는 실제 공 중심의 존 안/밖으로, 판정이나 의도가 아니다.

구종 계열의 공통 우열은 대부분 보류한다. 0-0은 설정한±0.01 W 안의 작은 범위, 3-2는 비포심 우세의 개발 단서가 남는다. 기존FB의3-0 차이는 소멸하거나 부호가 뒤집힌 것이 아니며 일부 분할 표본 부족·보정 의존성 때문에 보류한다.

타자는 존 안12카운트 모두 스윙 우세 점추정이지만3-0은 불명확하다. 존 밖 지원 셀은 테이크 우세 방향이며3-0 밖4구역은 자료 부족이다. 가운데는 존 안 전체이고 모서리는 두 보고 구역에 겹친다. 카운트 평균은 위치를 가리지 않는 행동 지시가 아니다.

## 권장 검수

1. **정의와 원자료 연결:** 좌표·좌우·행동·구종 코드·투구 전 카운트·시즌W·타석 종료 연결을 독립 대조. 기존 예외 및 완료 타석/고의볼넷 제외 영향을 확인한다.
2. **자료 분리와 독립 산술:** 경기별 분할, 훈련 내부 전처리·튜닝·선택확률 보정을 점검하고, 저장 점수에서 Q·차이·경기 군집 구간·표본·ESS를 별도 구현으로 재현한다. V2는 정책 학습을 수행하지 않았다.
3. **비교와 보정:** 행동 겹침·극단 가중치·제외 집단·선택확률 보정 상태와 단순 평균/결과모형/AIPW 차이를 확인한다. 0-2·1-2 S/B, 타자3-0, 구종3-0·3-1·3-2를 우선 본다.
4. **판정과 이력:** 기존219 비교와 구종 추가255 비교,0.01 W 참고선, 결과 전 고정과 결과 후 변경을 대조한다. 이 통합 보고서는 새로운 공동 유의성 판정을 하지 않는다.
5. **후속 학습 불확실성:** 앞 검수에서 필요성이 확인되면 제한된 재학습과 경기 간 선수/시리즈 의존성 처리를 별도 설계한다. 현재 구간은 고정 점수의 경기 의존성만 반영한다.
6. **후속 외부 재현:** 기준 고정 후 별도 자료로 확인한다. V1 검증을 V2에 전용하지 않으며 기존 연도 노출·2026 위치 측정 정합성을 확인한다. KBO는 별도 범위다.

1~4부터 진행하는 것이 비용 대비 합리적이다. 5~6은 이번 보고서 제작에서 실행하지 않았다. 선수 보정은 미측정 구위·컨디션·의도·예상 차이를 제거하지 못한다. 타자의 사후 공 특성 진단은 실시간 지각 정책과 다르다. 독립 산술 통과와 실제 행동 변경의 인과 효과 입증을 구분한다.

## 보고서 제작 확인 범위

입력 행 수: S/B12, 타자 카운트12, 타자5구역60, 구종 주요비교48. 표는 저장된 CSV의 값과 판정을 사용했다. 입력 파일 SHA256과 HTML 해시는 manifest에 기록했다. 이는 표현물 확인이며 모델 검수가 아니다.
