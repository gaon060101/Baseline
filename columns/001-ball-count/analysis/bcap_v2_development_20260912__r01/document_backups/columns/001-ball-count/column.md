## 핵심 피드백

- 투구 전 카운트 기준. 구종·위치, 타자 스윙, 투구 결과와 최종 타석 결과를 구분한다. 투수의 의도를 결과만으로 단정하지 않는다.
- 다음 공은 투구 단위, 최종 결과는 해당 카운트를 거친 타석 단위로 계산하며 같은 카운트 반복 방문을 중복 집계하지 않는다.
- 35개는 B/S만으로 볼넷·삼진까지 진행하는 모형의 완결 경로다. 실제 전체 타석 경로 수가 아니다. 카운트 불변 파울을 생략한 최초 도달 경로는 2-2가 6개, 3-2가 10개다.
- 풀카운트 첫 공부터 분석하며 직전 2-2 / 3-1 두 집단을 우선 비교하는 방안을 추천. 파울은 원본에 남기고 경로 요약에서만 처리한다.
- 결정구는 2스트라이크에서 던진 모든 공으로 정의하는 방안을 추천. 성공한 삼진 공만 분석하지 않는다.
- 좋은/나쁜 투수 집단의 기준은 미정. 선발/불펜을 구분하고 이전 기간 성적으로 나눈 뒤 이후 기간 운용을 비교하는 방안을 추천.
- 빈도와 예측은 다르며 예측에는 별도 평가 기간이 필요하다. 관찰 성과가 좋다고 최적 선택이나 인과관계로 단정하지 않는다.
- 자동 판정·결측·타석 결과 누락·파울 번트 등의 처리를 정해야 한다. KBO 제공 범위와 이용 조건은 미확인.

## 유불리 판정식과 실제 분석 확정 — 2026-09-07

- 상세 보고서·칼럼 삽입용 해석문: [카운트 공격가치 분석](analysis/count_advantage_2024_2025.md).
- 수치 원표: [지수·신뢰구간·최종 판정](analysis/runs/bcai_obs__mlb_2024_2025__20260907__r01/artifacts/advantage_count_results.csv), [타석 결과](analysis/runs/bcai_obs__mlb_2024_2025__20260907__r01/artifacts/advantage_pa_outcomes.csv), [다음 구·스윙·구종](analysis/runs/bcai_obs__mlb_2024_2025__20260907__r01/artifacts/advantage_pitch_explanators.csv).
- 전체 366,231 PA에서 고의볼넷 1,065, truncated 635, 최종 결과 결측 221, 타격방해 186을 제외한 **364,124 PA·4,859경기**. 모든 분석 PA에서 0-0이 관측됐다. 원본·기존 정제본은 유지한다. 과거 기본 표는 제외 대상도 분모에 포함했으므로 새 PA 비율과 소폭 다르다.
- 타석 최종 결과는 투구 순서를 정렬한 마지막 기록으로 연결하고 PA×카운트당 한 번만 집계한다. 실제 다음 구 통계는 기존 전체 구종 확인 투구 1,419,135구를 사용하며 반복 파울 뒤 투구도 포함한다. 서로 다른 분모를 섞지 않는다.
- W는 해당 연도 FanGraphs wOBA 가중치로 1B·2B·3B·HR·비고의 BB·HBP에 점수를 부여한 값이다. K·기타 OUT·OTHER는 0. OTHER(실책 출루·아웃 없는 야수선택)를 아웃으로 부르지 않는다. 희생번트도 PA 분모에 포함하므로 공식 wOBA 자체가 아니다.
- **I(c)=100×Σᵧqᵧ[Vᵧc/Vᵧ0]**. Vᵧc는 카운트 c 도달 PA의 평균 W, Vᵧ0는 연도별 0-0 평균, qᵧ는 전체 분석 PA 기준 고정 시즌 혼합비다. I=120은 시작점보다 가중 공격가치가 20% 높다는 뜻이며 실제 득점·승률 20% 증가가 아니다.
- 100은 타석 시작 평균이며 50:50 승부를 뜻하지 않는다. ±5/15 경계는 설명용 효과 크기 기준으로 사용하고 경기 단위 2,000회 부트스트랩의 동시 95% 구간으로 최종 판정한다. 경계를 걸치면 중립으로 단정하지 않고 경계 불확실을 표시한다. 세부 가중치·정확한 경계 포함 규칙은 상세 보고서를 따른다.

0-2가 가장 투수에게, 3-0이 가장 타자에게 유리한 관찰 상태였다. 3볼의 높은 가치는 안타 빈도뿐 아니라 볼넷에서 나온다. 0-1 대 2-2, 1-0 대 2-1의 미세한 점추정 순위는 확정적 우열로 쓰지 않는다.

타자·투수×시즌, 좌우 조합, 구장×시즌, 점수 차, 주자, 아웃, 이닝을 타석 시작 시점에서 잔차화한 경기별 교차 적합 진단의 중심 설정(α100)은 최대 1.77포인트 이동했다. 이는 선택 편향을 제거했다는 증거가 아니다. 보정 모형의 낮은 설명력·반복 한도와 남은 교란은 상세 보고서에 명시한다. 주 결과는 실제 도달 집단의 관찰 지수다.

### KBO를 보기 전에 기록한 탐색 가설과 비교 규칙

1. 0-2 최저·3-0 최고, 같은 스트라이크 수에서 볼 증가에 따른 지수 상승, 같은 볼 수에서 스트라이크 증가에 따른 하락, 3-2의 시작점 대비 타자 우위를 검증한다.
2. KBO 자료의 투구 전 카운트·타석 키·최종 결과·구종/스윙 정의와 이용 조건을 먼저 확인한다. 기간은 미정이며 아직 KBO 자료로 확인하지 않았다.
3. 리그·시즌 자체 가중치와 0-0 평균을 쓰고 동일한 PA 제외·중복 처리·시즌 혼합비·등급 경계·구간 판정 규칙을 적용한다. 리그 득점 환경 차이는 wOBA scale과 리그 R/PA로 환산한 보조 지표도 병기한다. 공식은 상세 보고서 13절을 따른다.
4. 지수는 리그의 절대 실력 우열이나 카운트의 인과효과가 아니다. KBO 결과가 다르면 가설을 수정해 맞추지 않고 차이·불확실성을 보고한다.
