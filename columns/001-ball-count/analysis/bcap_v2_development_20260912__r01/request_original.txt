## 3. 모델이 답할 질문

목표는 개별 선수의 실행 능력을 평가하거나 행동을 지시하는 것이 아니다.

**같은 카운트와 비교 가능한 선수·상황에서 어느 행동 또는 실제 투구 방향이 평균적으로 더 좋은 최종 결과와 연결되는지** 찾는다.

- 투수에게 좋은 방향: 타자의 기대 공격가치가 낮은 쪽.
- 타자에게 좋은 행동: 자신의 기대 공격가치가 높은 쪽.

관찰 자료의 보정 비교로 해석한다. 실제 지시 변경의 인과효과나 모든 투구에 반복 적용한 PA 전체 개선량이라고 부르지 않는다.

이 한계 때문에 계산된 방향을 숨기지는 않는다. 점추정 방향과 근거의 강도를 분리해서 보여준다.

## 4. 공통 변경: 구종 입력은 FB/NFB만

- FB: FF·SI·FC, 즉 포심·싱커·커터.
- NFB: 기존 명세에서 허용한 나머지 구종 코드.

현재·직전 세부 구종 범주를 모델 입력에 남기지 않는다. 직전 구종을 쓰면 직전 FB/NFB로 변환한다.

세부 구종 원본은 보존하고 매핑에만 사용한다. 미분류는 자동으로 NFB에 넣지 않는다. FA=Other 등 기존 분류의 한계를 설명한다.

구속·움직임 등 기존 타자 모델의 다른 입력은 이번에 불필요하게 바꾸지 않는다. 구종 범주를 제거하는 것과 공의 물리적 특성을 모두 제거하는 것을 혼동하지 않는다.

## 5. 투수 A: 실제 S/B 비교 추가

정의:

- **S: 실제 존 안에 도착한 공.**
- **B: 실제 존 밖으로 간 공.**
- 투수의 의도나 기록상 ball/strike 판정이 아니다.
- 존 안 공이 홈런이 되어도 S.
- 존 밖 공에 헛스윙이 나와도 B.

핵심 질문:

> S가 항상 좋은가? 어떤 카운트에서는 존 안 투구의 피안타 손해 때문에 B보다 더 높은 공격가치를 허용하는가?

2024·2025의 각 카운트에서 다음을 산출한다.

- 실제 S/B 비율.
- 같은 기준 집단의 S/B 보정 기대 최종 PA 공격가치.
- S−B 차이.
- 투수에게 더 유리한 점추정 방향.
- 비교 표본·공통 지지·차이의 불확실성.

S/B는 기존 좌표와 존 상·하단으로 일관되게 정의한다. 기존 INNER/BOUNDARY/OUT은 별도의 구역 분류이므로, BOUNDARY를 일괄 S 또는 B로 치환하지 않는다. 공 중심 기준인지 다른 기준인지 명세에 기록한다.

S/B를 결정하는 현재 좌표·존 파생값을 보정 입력에 다시 넣지 않는다. 현재 Swing·description·타구 결과·최종 결과도 보정 입력에서 제외한다.

새 S/B 모듈은 기존 투수의 투구 전 상황 변수와 현재 FB/NFB를 활용하는 간결한 설계를 우선한다. 현재 구속·움직임 등 추가 사후 조건화는 이번에 도입하지 않는다.

## 6. 투수 B: FB/NFB 비교 유지

기존 투수 모델을 재사용하되 직전 세부 구종 등 이번 변경 대상만 정리한다.

카운트별로 다음을 산출한다.

- 실제 FB/NFB 비율.
- 양 구종군의 보정 기대 공격가치.
- FB−NFB 차이와 더 낮은 쪽.
- 표본·공통 지지·불확실성.

이 주 비교에는 현재 실제 위치·S/B·Swing·타구 결과를 보정 입력으로 추가하지 않는다. 구종에 따라 위치와 타자 반응이 달라지는 경로를 별도로 제거하지 않는다.

개별 선수의 구종 실행 능력 평가는 하지 않는다. 단, 비교 자료가 부족한 상태를 모델 외삽으로 채우지 않는다.

## 7. 타자: 카운트·위치별 Swing/Take

기존 타자 모델을 재사용하고 세부 구종 범주를 FB/NFB로 바꾼다.

이번 위치 구역은 기존 **INNER·BOUNDARY·OUT**을 유지한다. 몸쪽·바깥쪽·높낮이의 새로운 세부 격자는 만들지 않는다.

카운트별로 다음을 보여줘.

1. 실제 Swing/Take 비율.
2. 같은 기준 행에서 양 행동의 보정 기대 공격가치.
3. Swing−Take 차이와 더 유리한 점추정 방향.
4. 어느 위치 구역으로 공이 가장 많이 왔는지.
5. 위치별 실제 스윙률.
6. 위치별 Swing/Take 가치 차이.
7. FB/NFB에 따라 방향이 달라지는 부분.

위험과 이득은 다음처럼 정의한다.

- **스윙이 위험한 구역:** 테이크보다 스윙의 예상 공격가치가 낮은 곳.
- **테이크가 위험한 구역:** 스윙보다 테이크의 예상 공격가치가 낮은 곳.
- **행동 선택 차이가 큰 구역:** 두 행동의 예상 공격가치 차이가 큰 곳.

가장 자주 오는 구역과 가치 차이가 가장 큰 구역을 구분한다. 실제 스윙률을 함께 보여주되, 특정 선수의 고유 약점이나 행동 교정으로 확실히 회수할 수 있는 득점이라고 해석하지 않는다.

기존의 번트 포함 공격 시도·판정상 Take 정의를 유지하고 표에 설명한다. HBP·체크스윙·결측·미분류의 한계도 유지한다.

현재 공의 위치·구속·움직임은 사후 측정 정보다. 실시간 타자 지각을 그대로 관측했다고 표현하지 않는다.

## 8. 계산 방식은 기존 구조 재사용

주 결과 Y는 기존 시즌별 가중 최종 PA 공격가치 W를 유지한다. BCAI 지수나 전이 보상을 더하지 않는다.

- 실제 같은 선수·상황 행들에서 양 행동을 비교.
- 투수·타자 효과 보정과 기존 축소 방식 유지.
- 동일 경기의 PA·투구는 같은 fold에 배정.
- 기존 경기 단위 교차 적합 구조 재사용.
- 전처리·범주 사전·보정 모델 학습과 평가 행 분리.
- 정책 후보를 학습한다면 정책 선택과 평가도 기존 방식대로 분리.

여기서 자료 분리는 외부 검증이 아니라 개발 계산의 누수를 방지하기 위한 구조이므로 유지한다.

알고리즘은 기존 것을 우선 재사용한다. 하이퍼파라미터는 기존 개발 설정을 출발점으로 하고, 새 비교에 재선택이 필요하면 기존의 작은 후보 범위만 사용한다. 광범위한 탐색을 하지 않는다.

기존 공통 지지·표본 기준을 출발점으로 사용하고 새 행동에 적용한 의미를 기록한다. 기준을 통과했다고 인과적 타당성이나 모든 세부 상황의 비교 가능성이 보장된다고 표현하지 않는다.

## 9. ‘검증 제외’의 정확한 범위

이번에는 외부 재현·전면 독립 검수·재학습 안정성 검증을 수행하지 않는다.

다만 결과를 잘못 산출하지 않기 위해 다음 기본 확인은 수행한다.

- 투구 키 중복·행동 결측·유효 카운트.
- Y 연결 및 시즌 가중치.

- 계산 실패·비수렴·NaN·무한값.
- 양 행동의 동일 비교 분모.
- 투수·타자 가치 차이의 부호.
- 결과표의 표본 합계.

기존 카운트 예외 6행은 알려진 미해결 기록으로 표시한다. 이번에 대규모 카운트 감사나 원인 조사를 새로 시작하지 않고, 근거 없이 원본·라벨·행을 수정하지 않는다.

기본 확인이 실패하면 해당 문제는 해결하거나 해당 결과를 산출 보류한다. 확인하지 않은 것을 PASS로 기록하지 않는다.

## 10. 결과 표현과 구간

결과에는 다음을 분리해 표시한다.

- 점추정상 더 유리한 방향.
- 행동가치 차이.
- 표본·공통 지지.
- 기존 방식의 명목 근사 구간.
- 해석 제한.

기존 고정 점수 경기 변동 방식의 구간은 재사용할 수 있지만, 실제 95% 포함률·전체 학습 불확실성은 미검증이라고 표시한다. bootstrap이나 추가 재학습으로 구간을 확장하지 않는다.

기존 다중비교 상수를 새 출력에 무조건 복사하지 않는다. 실제 표시 범위에 맞는 간단한 보정 규칙을 결과 전에 정하거나, 개별 명목 구간임을 명확히 표시한다. 구간이 0을 제외했다는 이유만으로 확정 권고로 승격하지 않는다.

‘점추정 방향’, ‘차이 불명확’, ‘비교 자료 부족’을 구분한다. 인과 권고가 검증되지 않았다는 이유로 모든 결과를 “아무것도 알 수 없음”으로 요약하지 않는다.

## 11. 저장·버전·최종 보고서

V2는 두 번째 개발 세대라는 사용자 명칭이다. 실제 모델 ID·버전은 프로젝트 규칙에 따라 선택하고 근거를 짧게 기록한다.

기존 원본·정제본·v0.1 모델·완료 실행·봉인은 보존한다. 새 계산은 실제 날짜와 미사용 실행 ID를 사용한다.

새 실행에는 코드·설정·입력 연결·핵심 입출력 해시·환경·분할·행별 예측·결과·기본 확인 기록을 남긴다. 이미 존재하는 원본 전체를 반복 해시하는 감사는 하지 않는다.

후속 검수에 필요한 적합 객체·범주 사전·calibration·훈련 키 또는 분할 연결을 가능한 중복 없이 보존한다. 보존하지 않은 항목은 기록한다.

보고서는 **하나의 이해하기 쉬운 문서**를 중심으로 작성한다.

- 투수: 12카운트별 S/B 표.
- 투수: 12카운트별 FB/NFB 표.
- 타자: 12카운트별 Swing/Take 표.
- 타자: 카운트×기존 위치 구역의 투구 빈도·스윙률·행동가치 차이.
- 눈에 띄는 패턴과 차이가 불명확한 부분.
- 기존 V1과 달라진 점.
- 이번에 하지 않은 외부 검증·독립 검수 목록.

표마다 단위와 분모를 표시하고, 구종·위치별 후보의 미세한 순위를 확정적 최적 선택으로 쓰지 않는다. 필요하면 간단한 히트맵을 사용하되 별도 대규모 시각화 작업으로 확장하지 않는다.
