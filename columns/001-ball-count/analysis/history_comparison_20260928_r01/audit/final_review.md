# 역사 비교 보고서 최종 검수 — 2026-09-28

기존 산출물에서 이어서 검토·보완·전달 준비를 완료했다. 보고서의 분석을 처음부터 다시 수행하지 않았다.

## 완료한 내용

- 질문 → 짧은 답·수치 → 예시·근거 → 해석의 흐름과 주장 비교 14건을 검토했다. 존 안 12카운트 표를 본문에 직접 연결하고 2023년 0-2 CENTER·OUTSIDE의 저장된 스윙 차이·보정 구간·분모를 예시로 추가했다. OUTSIDE는 바깥쪽 한 구역임을 명시했다.
- 원 주장 장부의 ID·원문 경로·run ID, 주장 비교표의 파생 표 링크, 전체 결과표의 source_csv/source_manifest로 추적할 수 있어 중복 장부는 만들지 않았다. 새 수치 집계·그림 계산 없이 기존 R 산출물을 사용했다.
- 원본 그림 5장을 직접 열어 한국어·단위·범례·자료 부족 표기를 확인했다. 그림 2는 지수 위/W 아래, 그림 4는 CENTER 위/존 밖 아래 순서다. PC·모바일 본문 시작, 모바일 비교 카드, 통합 페이지 그림과 모바일 확대 화면도 확인했다.
- 모바일 그림의 작은 글씨를 위해 본문 내 확대·축소와 그림 내부 가로 스크롤을 추가했다. 기본 화면은 전체 모양, 확대 화면은 900px 원본 크기를 제공한다.

## 수치·보존 검산

[numerical_verification.json](numerical_verification.json): verify.R의 13개 검사 모두 통과. 12카운트·11시즌, 2,552개 BCAP 집단, 지원 기준, 미지원 값 보류, 차이·구간 공식, 연도 가중치, 범주 합계, 키 중복, 원천 보존 및 주장 근거 존재를 확인했다. 172개 입력 파일과 53개 완료 manifest를 기록하며 승인 원고도 해시 보존 대상이다.

이는 저장 출력의 산술·출처·보존 검사다. 원자료 재적합, 새 모델 검증, 구간의 실제 포함률 또는 인과 타당성 검증이 아니다.

[browser_verification.json](browser_verification.json): 재현 가능한 [check_report.mjs](../check_report.mjs)로 실제 Edge에서 HTML 13개를 1280px·390px로 검사했다. 26개 페이지/화면 조합에서 미로딩 이미지·깨진 로컬 파일 링크·내부 앵커·페이지 가로 넘침·오류가 없고, 모바일 넓은 표의 카드 전환을 확인했다. 추가로 그림 5개 확대 시 900px 폭과 페이지 넘침 없음을 검사했다. 스크린샷은 [browser 폴더](browser/)에 있다. 외부 웹 링크의 재접근 검사는 수행하지 않았다.

## 남은 해석 한계와 다음 작업

BCAP은 EXPERIMENTAL이다. 기준 공유 적합과 역사 연도별 적합, 측정·가중치·지원 집단 차이가 남는다. 연도별 구간은 역사 비교 전체의 동시 구간이 아니며 방향 반복을 연도 차이 검정·인과 효과·최적 선택·KBO 일반화로 바꾸지 않는다. 2026은 9월 7일 기준·2025 고정 가중치 보조이며 S/B·SWING은 측정 보류다. FanGraphs 과거 원문 접근 제한을 유지했다.
