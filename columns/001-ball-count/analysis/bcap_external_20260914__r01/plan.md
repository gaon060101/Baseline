# BCAP 외부 패턴 재현 계획 — 결과 전 고정

2026-09-14. 실행 가능한 규칙은 [plan.json](plan.json), 입력·설정·코드 해시와 고정 시각은 [plan_seal.json](plan_seal.json)이 기준이다. 새로운 V2 외부 결과를 계산하기 전에 고정한다. 외부 기관이 입회한 사전등록은 아니다.

## 대상과 자료

2023-03-30~10-01의 기존 720,684구·2,430경기, 2026-03-25~09-07의 기존 639,042구·2,165경기를 재사용한다. 기존 BCAI/Ridge·BCAP V1에 사용된 자료이며 완전히 미관측인 시험 자료가 아니다. 이번 작업에서는 과거 요약·입력 메타정보·개발 결과를 확인했고, 새 V2 외부 행동별 결과는 고정 후 계산한다.

2023은 S/B·SWING·FB/NFB·포심/비포심 네 모델, 2026은 두 구종 모델을 실행한다. [공식 측정 설명 확인](measurement_review.md)에 따라 2026 S/B와 SWING은 **측정 정합성 미확보로 보류**한다. 표본 부족이나 재현 실패로 분류하지 않으며, 판정상 볼·스트라이크나 임의 변환으로 대체하지 않는다.

기존 완료·적격 PA 선택, 투구 전 카운트, 닫힌 행동 분류와 사전 변수, 타자의 사후 측정 공 특성, 선수 축소 보정 및 지원 기준을 유지한다. 가운데는 존 안 전체, 모서리는 두 보고 구역에 포함하되 학습 행은 중복하지 않는다. 새 정제본은 별도 이름으로 저장하며 원본을 다시 수집하지 않는다.

## 적합과 추정

주 질문은 외부 집단에서 보정된 행동 가치 차이가 나타나는가이다. 각 외부 연도 안에서 경기 단위 3분할로 기존 V2 보조 모형을 한 번씩 적합한다. 개발 모델 전체 재적합·정책 학습·추가 seed·부트스트랩은 하지 않는다. 저장된 개발 모형의 고정 예측 성능은 이번에 별도로 시험하지 않는다. 외부 보조 모형의 MSE·Brier를 고정 개발 모델의 외부 성능으로 표현하지 않는다.

S/B의 개발 3분할은 선택확률·양 행동 결과 모두 규제 1000, 나머지 모델은 100/1000/1000으로 일치한다. 이 값을 외부에서 고정하고 다시 튜닝하지 않는다. seed는 기존 20260909, 정렬 경기 섞기 후 3분할, 각 바깥 분할 내부 보조 모형 seed는 20260909+2000+k다. 훈련 경기 내부 5분할의 0번은 선택확률 보정, 1~4번은 선택확률 적합에 쓰고 양 행동 결과 모형은 바깥 훈련 전체의 해당 행동 행을 사용한다. 범주 사전·중심화도 각 적합 훈련 안에서만 만든다.

미관측 범주의 효과는 기존 규칙대로 0이며 외부 훈련 안에서 양 행동 30개 이상의 선수 지원을 충족하지 못하면 지원을 보간하지 않는다. propensity 0.05~0.95, 집단 n≥500·행동별 ESS≥200·행동별 경기≥100·포함률≥0.5·최대 경기 가중치 비중≤0.05를 유지한다. 개발 선수 명단 대비 미관측과 외부 보조 모형 훈련 대비 미관측을 구분한다.

Y는 최종 PA에 시즌 가중치를 적용한 W다. 2023은 기존 2023 값, 2024·2025는 각 시즌 값, 2026은 2025 값을 고정한다. 산출 방식은 같지만 계수가 다른 척도이므로 연도별 차이 크기를 완전히 같은 단위계수로 직접 비교하지 않는다. 확률·득점으로 바꾸거나 PA 내 투구 차이를 합산하지 않는다.

## 비교 범위·판정

- 주 비교: S/B의 0-2·1-2 × 2023·2026 = **4개**, 양수 `S−B` 예상. 2026 보류 뒤에도 Bonferroni 분모 4를 유지한다.
- 보조 비교: 두 연도 × (S/B 나머지 10카운트 + SWING 60개 카운트·구역 + 구종 두 분류×12카운트×자체/공통 표본) = **236개**. 측정 보류 항목도 분모에 남긴다.
- 개발의 기존 219/255 구간은 보존한다. 외부의 4/236은 다른 사전 지정 비교 묶음이며 결과를 보고 좁힌 것이 아니다. 외부 보정 구간과 기존 개발 구간을 같은 엄격도의 구간으로 설명하지 않는다.
- 같은 평가 행에서 단순 평균·결과모형·AIPW를 비교한다. 구종 분할별 3개 결과와 개별 명목 구간은 보조적인 방향·표본 진단이며 새 유의성 주장이 아니다.

배타적 판정 순서는 측정 보류 → 기존 지원 기준 미달이면 자료 부족 → 기준 방향과 같고 보정 구간이 0을 제외하면 같은 방향 재현 → 반대이고 구간이 0을 제외하면 반대 방향 → 나머지는 불명확이다. 반대 점추정이라도 구간이 0을 포함하면 불명확으로 두고 점추정 방향을 별도 표시한다. 개발에서 미확정이었던 셀은 이력을 표시하며 확정 가설의 재검증으로 부르지 않는다.

점추정 방향, 구간의 0 제외, 방향을 맞춘 구간 전체의 0.01 W 이상 여부, 구간 전체가 ±0.01 W 안인지, 추정 방식별 부호 반전은 각각 표시한다. 불명확을 동등성으로 바꾸지 않는다.

## 기록·종료

기존 고정 점수의 경기 군집 t(G−1) 구간을 사용한다. 같은 경기 내 반복 PA·투구를 반영하지만 전체 재학습 변동과 경기 간 선수·시리즈 의존성은 포함하지 않는다. 주요 S/B는 저장 예측값부터 별도 산술로 검산한다.

새 실행에 입력·설정·분할·적합·예측·점수·표본·ESS·선택확률·극단 가중치·수렴·금지 입력 확인을 보존한다. 개발/2023/2026을 나란히 보이는 한국어 보고서와 칼럼 결론을 작성하고 실제 수행 범위만 문서에 반영한다. 모형 상태를 자동으로 VALIDATED로 올리지 않는다. 가능한 결과와 측정 보류를 정리하면 종료하며 원하는 결과를 얻기 위한 후속 탐색은 하지 않는다.
