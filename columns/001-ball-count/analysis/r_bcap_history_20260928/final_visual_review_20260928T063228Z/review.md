## 원 집계와 표시의 일치

최종 보고서의 **2,552행 전체를 원 실행의 year_values.csv와 모든 원 필드별로 대조해 정확히 일치**함을 확인했다. 추정값을 다시 계산한 검증은 아니며, 원 집계가 보고서로 그대로 전달됐는지 확인한 것이다.

전체 48개 그림의 저장된 실제 패널 축 검증을 확인했다. 기본 528개 카운트 중 527개가 지원 기준을 통과한다. 유일한 기본 자료 부족은 **PITCH 2020년 3-0**이다. 최종 PITCH 종합 그림에서 해당 위치에 점·구간이 없고 ‘자료 부족’ 문구만 있는 것을 직접 확인했다. 이를 차이 0으로 읽으면 안 된다.

2015년 기본 카운트는 네 모델 모두 12/12 지원된다. 다만 **2015 SWING 세부 비교 27개는 자료 부족**으로 남는다. 세부 집계의 자료 부족 라벨과 방향 표시 없음도 유지된다. 기본 그림에서 점을 모두 표시한다고 모든 세부 집단의 지원이 충분하다는 뜻은 아니다.

## 구속 측정 주의문과 해석 범위

새 2015 모바일 그림 4장에 다음 캡션이 실제로 보이고 잘리지 않는다.

> 구속: 보정 PITCHf/x · 2017년 이후와 측정 차이 유의

종합 4장에도 ‘2015·2016년 구속’으로 대상을 명시한 같은 제한이 들어 있다. 저장된 그림 검증에서 주의문이 필요한 12장(2015·2016 모바일 8장과 종합 4장) 모두 캡션 포함이 확인된다. 구속에 관한 출처 범위를 지켰으며, 모든 물리 변수를 PITCHf/x로 분류하거나 2017년 이후와 측정이 동등하다고 주장하지 않는다.

조건부 구간은 저장 OOF 점수를 고정한 근사이며 전체 학습 변동·경기 간 선수 의존성·실제 95% 포함률까지 검증한 것은 아니다. 여러 해를 나란히 놓은 그림은 연도 차이 검정이나 행동 추천이 아니다. 보정수는 실행별 기준이며 전체 11년을 한꺼번에 보정했다고 해석하지 않는다. 2020 단축 시즌과 2026 별도 보조 분석·위치 및 SWING 측정 보류는 보고서의 기존 설명을 따른다.

이번 작업에서는 재렌더·재적합·통계값·모델·보고서 생성 코드 변경을 하지 않았다. 육안 확인 범위는 위 8장이며, 다른 모바일 그림의 실제 열람 여부는 이전 날짜별 검수 기록을 따른다. 보존 HTML은 원 위치의 상대 링크를 유지한 원문 사본이다.
