# BCAP R 연도별 계산

2024·2025 기존 분석의 R 재현과 2023→2015 네 모듈 적용을 완료했다. [전체 계획](../r_history_20260928/plan.md)과 [칼럼 상태](../../column.md#current-status)가 범위의 기준이다. [결과 보고서](report.html)는 11시즌·44개 모델/연도 조합을 담았다. 새 연도 적합은 관찰상 보정 비교이며 인과 검증·행동 추천이 아니다.

## 파일과 읽는 순서

- `progress.json`: 이 순차 실행기의 실제 진행·실패 기록. 프로세스가 강제 중단되면 마지막 RUNNING 표시는 살아 있는 프로세스를 보증하지 않는다.
- `report.html`, `report.md`, `summary.csv`: 완료 manifest와 저장 집계표만 모은 결과. 실패·미완료 연도는 완료처럼 표시하지 않는다.
- `implementation_review.md`: 별도 구현 검토 범위와 한계.
- `<run_id>.config.json`, `<run_id>.log`, `execution_code/<run_id>/`: 연도·모듈별 설정, 실행 출력, 실행 전 코드 사본.
- 개별 실행의 기준은 `../runs/<run_id>/manifest.json`이다. 네 모듈은 `pitch`, `pitch_sb`, `swing`, `pitch_ff`다.

## 다른 연도에 적용하는 방식

저장소 루트에서 실행한다. `python`과 `Rscript`는 설치된 실행 파일의 절대 경로로 바꿀 수 있다. 아래는 승인된 역사 범위의 실행 예시다. 이미 프로세스가 동작 중이면 다시 시작하지 않는다.

```powershell
python tools/run_bcap_history.py --years 2023 2022 2021 2020 2019 2018 2017 2016 2015 --rscript 'Rscript.exe' --wait-for-inputs --preparation-attempt 2
```

먼저 2024·2025 네 모듈의 점수·지원 표본 재현 통과를 확인한다. 완료된 BCAI 역사 실행에서 원 CSV·일정·가중치를 찾고 해시를 대조한다. 준비와 통계 계산은 모두 R에서 수행하며 Python은 파일 확인과 실행 순서만 관리한다. 원자료를 새로 다운로드하는 도구가 아니다.

완료 결과는 재사용하고, 미완료 실행은 보존한 채 멈춘다. 실패를 검토한 재실행에는 새 run ID와 설정·로그·코드 경로가 필요하다. 날짜만 바꿔 자동으로 실패를 숨기지 않는다. 동일 묶음의 동시 실행은 OS 잠금으로 차단한다.

`--check-only`는 선행 재현 검사와 현재 입력 연결만 확인한다. `--wait-for-inputs`가 없으면 BCAI 입력이 아직 완료되지 않은 연도에서 중단한다. 기다리는 동안 BCAI의 해당 연도 실패나 접근 거부 기록이 확인되면 계산을 진행하지 않는다.

2023의 첫 준비는 일정 API의 같은 경기 중복 레코드 46개를 발견해 계산 전에 중단했다. 연기·재개로 중복된 레코드에서 연도·구장·공식일·기준일이 모두 같은 경우만 한 경기로 묶고, 충돌은 계속 거부하도록 보강했다. 실패한 `data/processed/r_bcap_history_20260928/2023/`의 설정·로그를 보존하고 `r02/`에 새 준비를 만든다. 위 `--preparation-attempt 2`가 그 경로를 지정한다. 이전 진행표도 `progress_attempts/`에 보관한다.

보고서만 갱신하려면 다음을 사용한다. 원자료·학습 결과는 바뀌지 않는다.

```powershell
./tools/run_r.ps1 -Script tools/render_bcap_history.R
```

## 연도를 비교할 때

각 역사 연도는 그해 안에서 새로 3분할한 적합이다. 2024·2025의 공동 개발 적합을 연도별로 나눈 표와 역할이 다르다. 나란히 그린 선을 연도 간 차이 검정으로 해석하지 않는다. 구간은 고정 점수의 경기 군집 조건부 구간이며 보조 모형 재학습 변동은 포함하지 않는다.

2024·2025 재현 실행만 원 Python 행별 점수와 대조했다. 역사 실행에는 원 참조 점수를 주입하지 않으며 새 R 분할로 계산한다. 초기 동결 실행기의 `checks.json.scope`에 원 점수 재현이라는 공통 문구가 남은 경우에도 실제 해당 검사가 없으면 재현 검증을 수행한 것이 아니다. 후속 실행기에서는 참조 존재 여부에 따라 문구를 나누었다. 과거 실행·검사 파일은 고쳐 쓰지 않는다.

네 모듈의 232개 보고 집합에는 연도 안에서 미리 정한 보수적 Bonferroni 상한255를 적용한다. 여러 연도 전체의 동시 보장은 아니다. 시즌마다 공격가치 가중치가 다르고, 2015·2016 물리량 측정 방식과 2020 단축 시즌도 한계다. 2026 S/B·SWING은 측정 정합성 보류를 유지한다.

큰 RDS·행별 입력은 Git 공유 대상에서 제외한다. [제외 목록](../../../../guides/excluded_files.json)에 역할과 재생성 방법을 기록하며 로컬 파일은 보존한다.
