# 2019년 BCAP 저장 결과·모바일 그림 검수

**2019년 네 분석의 저장 검사·수렴 기록과 모바일 그림에 새 결함을 발견하지 못했다.** 기본 카운트 48개는 모두 지원 기준을 통과했다. SWING의 세부 비교 25개는 ‘비교 자료 부족’으로 유지되며, 이 표시를 누락하거나 기본 카운트 결과와 혼동하지 않아야 한다.

## 확인한 사본과 범위

- 보고서 생성 시각: **2026-09-28 13:42:28 KST**.
- 사본 확보 기준 시각: 2026-09-28 13:57 KST 이후. 실제 UTC 시각과 파일별 해시는 [사본 원장](snapshot_manifest.json)에 기록했다.
- 해당 보고서는 2019~2025의 완료된 **28개 모델·시즌**을 포함한다. 본 검수는 **2019년 4개 실행과 모바일 PNG 4장**에 한정한다.
- 보고서·집계·2019 그림·실행별 저장 결과 28파일을 먼저 복사했다. 복사 전후 원 보고서 검증 파일의 SHA256이 같고, 복사본도 원장 해시와 모두 일치한다.
- 보고서 검증 파일 SHA256: `23f43fe6be3a342695eae73dba439b4de314a54e199358e741efa61de1e0a05d`.
- 2018년 및 이후 자동 갱신된 보고서는 이번 검수에 포함하지 않는다. 렌더러 실행, 모델 재적합, 원 결과 수정은 하지 않았다.

네 실행 모두 `COMPLETE`, 모델 상태는 `EXPERIMENTAL`이다. 실행별 저장 검사 28개, 총 112개가 PASS이며, 각 metrics에 저장된 12건 적합의 전체 수렴 플래그가 TRUE다. 이는 저장된 검사·수렴 기록을 확인한 것이며 원 점수를 다시 계산하거나 적합을 반복한 검증은 아니다.

전체 232개 집계행에서 표본 수, 행동별 유효 표본 크기·경기 수, 지원률, 경기 가중치 집중도와 저장 기준을 대조해 지원 플래그가 일치함을 확인했다. 지원 부족은 ‘비교 자료 부족’, 지원 충분·보정 구간의 0 포함은 ‘차이 불명확’, 나머지는 ‘관찰상 방향 뚜렷’으로 일치한다. 지원 부족 행의 방향 표시와 모든 행의 추천 필드는 비어 있다. 카운트 합계, 행동별 분모, Q1−Q0 항등식도 확인했다. 상세 결과는 [검증 JSON](qa_validation.json)에 있다.

2019년 실행의 보정수는 모두 255다. 기본 카운트의 지원 통과가 모든 세부 집단의 지원 통과를 뜻하지 않으며, 특히 SWING의 자료 부족 25개는 세부 집단에 남아 있다. 구간은 관측된 OOF 점수를 고정한 경기 군집 조건부 근사이고, 전체 학습 불확실성·인과성·행동 추천의 검증을 뜻하지 않는다. checks의 범위도 원 점수 재현을 하지 않은 구조·수치 검사로 명시되어 있다.

다음 사본 PNG 4장을 모두 직접 열었다. 각 그림은 900×1350px이며, 원 파일 경로와 SHA256은 [검증 JSON](qa_validation.json)의 `viewed_png`, `viewed_png_sha256`에 있다.

2019년 제목, 해당 연도별 적합 설명, 0-0부터 3-2까지의 카운트 순서, 비교 방향, 공격가치 단위, 보정 255 조건부 구간과 EXPERIMENTAL 표시를 확인했다. 글자 잘림이나 눈금 겹침을 발견하지 못했다. SWING에는 번트 포함 표시가 있고, 3-0의 넓은 구간도 잘리지 않는다. PITCH의 3-0은 지원된 값으로 정상 위치에 놓인다. 2019 그림에 자료 부족 표시가 없는 것은 기본 12개 카운트가 모두 지원되기 때문이다.

그림마다 가로축 범위가 다르므로 모델·연도 간 선의 길이만 비교하면 안 된다. 보고서에 이 제한이 명시되어 있다. 보고서는 2015·2016 PITCHf/x와 이후 Statcast의 측정 차이, 2020 단축 시즌, 2026 측정 보류 및 허브 제외를 유지한다. 이 검수에서는 해당 연도의 새 그림을 확인한 것으로 주장하지 않는다.
