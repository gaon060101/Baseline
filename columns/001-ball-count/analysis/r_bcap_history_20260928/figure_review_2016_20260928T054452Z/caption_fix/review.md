# 구속 측정 주의문을 그림에 포함한 뒤 검수

**2015·2016년 그림에 구속 측정 방식의 차이가 직접 보이도록 캡션을 수정했다.** 수정 후 2016 모바일 그림 네 장을 다시 열어, 900×1350px 안에서 문구·축·구간이 모두 잘림 없이 보이는 것을 확인했다.

추가한 문구는 다음과 같다.

> 구속: 보정 PITCHf/x · 2017년 이후와 측정 차이 유의

구속에 관한 출처 범위를 지켰으며, 다른 측정 변수까지 PITCHf/x라고 표시하지 않았다. 종합 그림에도 포함된 2015·2016년을 명시하는 같은 주의문이 붙는다. 모든 네 BCAP 모델에 적용된다.

## 수정 전후와 보존 확인

- 수정 전 보고서: **2026-09-28 14:44:03 KST**, 40개 모델·시즌.
- 수정 후 보고서: **2026-09-28 15:04:43 KST**, 40개 모델·시즌.
- 보고서·그림·생성 코드 49파일을 각각 `before/`, `after/`에 보존했다. [수정 전 원장](before_snapshot.json), [수정 후 확인](postflight.json), [실제 그림 열람 기록](visual_review.json)을 함께 저장했다.
- 기존 집계 **2,320행**의 값과 메타데이터가 모두 정확히 유지됐다. summary.csv 자체도 수정 전후 SHA256이 같다: `55d222b81b014f7637636e3b5c86724ad713591239fb43d2c718e8ee517ca18a`.
- 원 분석 입력·산출물 **180개**의 해시도 모두 유지됐다.
- 전체 그림 **44장**의 카운트 축 순서 검증 PASS. 주의문이 필요한 모바일 4장과 종합 4장, **8장** 모두 실제 ggplot 캡션에 문구가 포함됨을 확인했다.
- 이번 변경으로 바뀐 PNG는 2016 모바일 4장과 종합 4장뿐이며, 나머지 모바일 36장은 동일 해시다.

수정 파일은 `tools/render_bcap_history.R`뿐이다. 모델 코드·적합·추정값·구간·지원 판정은 변경하지 않았다. 생성 코드의 새 SHA256은 `968fae2b148242effafff9db3c539cf724e39066c9c4e6089af687cc59322c4f`이다.

네 장 모두 추가 캡션이 오른쪽이나 아래쪽에서 잘리지 않는다. 한글·카운트 순서·점·구간도 정상이다. 3-0의 위치와 SWING의 넓은 구간도 유지된다. 종합 4장의 캡션은 생성 객체 검증으로 확인했으며, 이번 수정 후 육안 열람했다고 기록하지 않는다.

2015년도 같은 조건으로 주의문이 붙도록 했지만 **2015 PNG는 아직 실제 열람하지 않았다.** 이후 자동 갱신 결과와 미완료 연도는 이 검수에 포함하지 않는다. 최초 [2016 검수 기록](../review.md)의 ‘PNG에 주의문이 없다’는 사항은 수정 전 사본의 상태이며, 현재 수정본에서 해결됐다. 2017년 이후와 물리량 구간의 직접 비교가 검증됐다는 뜻은 아니다.
