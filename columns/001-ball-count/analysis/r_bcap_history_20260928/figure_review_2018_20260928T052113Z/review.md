# 2018년 BCAP 모바일 그림 검수

**2018년 BCAP 모바일 PNG 4장을 직접 확인했으며, 수정이 필요한 표시 문제는 발견하지 못했다.** 한글, 카운트 순서, 비교 방향, 단위와 조건부 구간 설명이 읽히고, 점·구간이 잘리지 않는다.

## 고정한 보고서 사본

- 대상 보고서 생성 시각: **2026-09-28 14:04:11 KST**, 완료 **32개 모델·시즌**(2018~2025).
- 검수 시작: 2026-09-28 14:21 KST. 정확한 보존·검수 시각은 [사본 원장](snapshot_manifest.json)과 [시각 검수 JSON](visual_review.json)에 저장했다.
- 보고서·집계·2018 그림·관련 실행 파일 28개를 먼저 복사하고 원장 SHA256과 대조했다. 복사 전후 보고서 검증 파일의 해시가 동일하여, 자동 갱신 중인 서로 다른 판본이 섞이지 않았다.
- 대상 보고서 검증 파일 SHA256: `40b0e8d09ec75c56973d10cf0906a02edaeabadd93f79a6b720b29cf2bd2c6ab`.
- 보존 사본 28개 해시가 모두 일치하며, 완료된 2018 실행의 원 파일 20개 해시도 검수 종료 시 그대로다.

네 그림 모두 2018년 제목, 해당 연도 안에서 별도 적합했다는 설명, 위에서 아래로 0-0부터 3-2까지의 순서를 확인했다. 3-0은 2-2 다음, 3-1 앞에 위치한다. SWING의 번트 포함 문구와 넓은 3-0 구간도 잘리지 않는다. 공격가치 단위, 경기 군집 조건부 구간, 보정수 255, 관찰상 비교와 EXPERIMENTAL 표시를 확인했다. 그림마다 가로축 범위가 다르므로 선 길이만으로 모델·연도를 비교하면 안 된다는 설명은 보고서에 유지되어 있다.

그림에 사용한 기본 카운트 48행의 값·보정 구간·지원 플래그·해석 라벨은 원 실행 집계와 일치한다. 모든 기본 카운트가 지원 기준을 통과하므로 이 네 그림에 ‘자료 부족’ 문구가 없는 것은 정상이다. 다만 **SWING 세부 비교 23개는 여전히 ‘비교 자료 부족’**으로 저장되어 있다. 기본 카운트 그림의 정상 표시를 세부 집단 전체의 충분한 지원으로 확대하면 안 된다.

## 검수의 범위

이 기록은 **2018년 모바일 PNG 4장과 14:04:11 KST 보고서 사본**의 표시·지원 라벨·원 집계 연결만 다룬다. 2017년, 이후 자동 갱신분, 이번에 열지 않은 종합 그림을 확인한 것으로 간주하지 않는다. 적합과 수치의 독립 감사는 별도 기록의 범위다.

재렌더, 통계 재계산, 모델·원 결과·보고서 생성 코드 변경은 하지 않았다. 구간은 저장된 OOF 점수를 고정한 경기 군집 조건부 근사이며 인과 효과나 행동 추천을 뜻하지 않는다. 보고서는 2015·2016 측정 체계 차이, 2020 단축 시즌, 2026 측정 보류 및 허브 제외에 관한 제한도 유지한다. 보관한 HTML은 원 위치의 상대 링크를 유지한 원문 사본이다.
