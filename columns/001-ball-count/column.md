[모델 발전 검토](model_research_followup_20260917.md)와 [다른 작업 전달 프롬프트](model_followup_prompt_20260917.md)를 저장했다. 기존 12카운트 S/B 결과를 확인했고, 실제 볼/스트라이크 상태 전이·사건 분해·상대 반응 분석은 후속 제안이다. 모델·실행·원본은 수정하지 않았다. BCAI 경로 직접 분석 대신 외부 결과를 쓰되 자체 검증으로 취급하지 않는다.

- 타석 최종 결과는 투구 순서를 정렬한 마지막 기록으로 연결하고 PA×카운트당 한 번만 집계한다. 실제 다음 구 통계는 기존 전체 구종 확인 투구 1,419,135구를 사용하며 반복 파울 뒤 투구도 포함한다. 서로 다른 분모를 섞지 않는다.

- **I(c)=100×Σᵧqᵧ[Vᵧc/Vᵧ0]**. Vᵧc는 카운트 c 도달 PA의 평균 W, Vᵧ0는 연도별 0-0 평균, qᵧ는 전체 분석 PA 기준 고정 시즌 혼합비다. I=120은 시작점보다 가중 공격가치가 20% 높다는 뜻이며 실제 득점·승률 20% 증가가 아니다.
- 100은 타석 시작 평균이며 50:50 승부를 뜻하지 않는다. ±5/15 경계는 설명용 효과 크기 기준으로 사용하고 경기 단위 2,000회 부트스트랩의 동시 95% 구간으로 최종 판정한다. 경계를 걸치면 중립으로 단정하지 않고 경계 불확실을 표시한다. 세부 가중치·정확한 경계 포함 규칙은 상세 보고서를 따른다.
