# GitHub 공유 범위

저장소: https://github.com/gaon060101/Baseline · 기준일: 2026-09-16.

이 저장소는 전체 로컬 백업이 아니라 **코드·문서·모델 정의·집계 결과 공유본**이다. 로컬 원본과 완료 실행은 그대로 보존한다. Google Drive/Docs 자동 동기화와 무관하다.

## 포함/제외

- 포함: 분석/재현 코드, MD·HTML 보고서, 모델 카드/명세, 실행 manifest·검증 기록, 집계 CSV·차트.
- 제외: MLB 원본/일정 스냅샷, 행별 정제·예측·분할 자료, pickle 모델/캐시, numpy 재표본 배열, 설치 라이브러리·bytecode·로컬 설정·문서 동기화 작업 자료.
- 기존 manifest는 역사적 실행 전체를 설명하므로 Git에 없는 파일도 가리킨다. 삭제 오류로 보거나 과거 manifest를 공유본에 맞춰 고치지 않는다.
- [파일별 제외 목록](excluded_files.json): 경로·바이트·역할별 분류·제외 이유·복원 안내. 현재 확인된 파일 352개. 런타임 일부는 권한상 열거하지 못해 폴더 전체 제외로 표시했다.
- [데이터 준비 안내](data_setup.md): MLB에서 받을 원본과 코드로 재생성할 파일을 구별한다.
- 다운로드·원본 재배포 허용을 CSV 제공만으로 단정하지 않는다. 자료가 필요한 팀원이 조건을 확인한 뒤 해당 분석 범위만 직접 확보한다.

## 새 파일을 올릴 때

.gitignore가 자동으로 모든 민감자료나 새로운 이름의 행별 CSV를 알아내는 것은 아니다. push 전 추가 파일의 내용·크기를 검토하고 제외 목록을 갱신한다. 토큰·쿠키·비밀번호·개인 환경은 절대 넣지 않는다. LFS나 원본 공유를 자동으로 켜지 않는다.

과거 코드의 절대 경로·날짜/ID가 다른 PC에서 그대로 동작한다고 보장하지 않는다. 재현 문서를 읽고 새 경로·새 실행 ID·새 봉인을 사용한다. 공유용 클론에는 제외 자료가 없으므로 기존 전체 해시/분석 검증은 입력 복원 전 실패할 수 있다. 이를 모델 검증 실패나 성공으로 바꾸어 기록하지 않는다.

## 이번 업로드 범위

모델 수치·분석 코드는 변경하지 않는다. 새 데이터 수집·모델 재학습·KBO 분석은 수행하지 않는다. 원격 초기 커밋을 부모로 유지하며 강제 push하지 않는다.
