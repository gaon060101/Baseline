# 집필 원칙

## 원고 관리
- 칼럼별 `column.md`를 중심 문서로 사용한다. 기획 메모와 본문을 구분한다.
- Google Docs 공동 집필을 시작하면 해당 Docs를 본문의 최신본으로 지정하고 `column.md`에 링크한다. `column.md`는 질문·가설·분석 결과·상태를 관리하며, 로컬 원고 사본에는 기준일을 표시한다. 세부 운영은 `collaboration.md`를 따른다.
- 기본 독자층은 야구를 좋아하지만 세이버 지표와 통계에는 익숙하지 않을 수 있는 팬으로 둔다. 칼럼별 요청이 있으면 조정한다.
- 원고는 질문 → MLB에서 발견한 패턴과 가설 → KBO 검증 → 해석과 한계의 흐름을 기본으로 하되 주제에 맞게 조정한다.
- 확인된 사실, 분석 결과, 작성자의 해석을 구분한다.
- 지표는 처음 등장할 때 뜻과 해석 방법을 설명한다. 계산법은 정확성을 유지하면서 읽기 쉽게 풀어 쓴다.
- 원고의 실제 수치에는 추적 가능한 출처 또는 해당 분석 결과를 연결한다. 참고 문헌은 칼럼별 `sources.md`에 정리한다.

## 시각자료와 발행
- 표와 차트에 제목, 단위, 기간, 표본 수, 출처를 표시한다.
- 인스타그램 자료는 칼럼 결과가 정리된 뒤 핵심 내용을 카드별로 구성한다. 요약 과정에서 불확실성과 결론의 범위를 왜곡하지 않는다.
- `figures/`는 표·차트, `publish/`는 검토된 발행용 원고와 인스타그램 문구·이미지에 사용한다.
- 실제 발행 전에는 상태를 “발행”으로 표시하지 않는다.
