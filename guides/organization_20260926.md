- 사용량 환산 문서는 운영 참고자료로만 연결했다. 요금·사용량을 재계산하지 않았다.

### 링크·상태·Git

- 추가·수정·보관 문서 7개의 로컬 Markdown 인라인 링크 224곳을 검사했고 깨진 경로·Markdown 앵커는 0곳이었다.
- 전체 검사 대상 MD는 176개에서 179개, 로컬 인라인 링크는 2,294곳에서 2,360곳이 됐다. 기존 오류는 과거 보관 문서 45개에 있는 상대 경로 782곳(문서·대상 조합 768개)이며 정리 전후 동일하다. 새 오류나 이번 작업으로 해결한 오류는 모두 0곳이다.
- 기존 오류는 `document_backups/`, `prior_documents/`, `bcap_document_backups_20260909_r01/`, `bcap_original_handoff_20260909/`, `revisions/v1/`, `revisions/v2/` 등 이동·보관된 문서에 있다. 원래 위치 기준 상대 경로를 가진 이력이므로 원문 보존 범위에서 그대로 두었다. Git 공유본의 제외 입력 문제와도 별개다.
- 링크 검사는 코드 블록 밖 Markdown 인라인 파일 경로·단순 제목/명시적 앵커 대상으로 수행했다. 외부 URL 접속, HTML 렌더·앵커, 브라우저 배치는 검사하지 않았다. 기존 HTML을 재생성하지 않았다.
- README와 `column.md`의 현재 상태 문자열이 일치한다. 기존 경로·모델 ID·실행 ID는 변경하지 않았고 역할별 구조도 실제 폴더와 대조했다. 05 HTML 부재와 index의 05 미연결도 별도로 확인했다.
