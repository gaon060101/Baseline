# 아직 확인이 끝나지 않은 인수인계

이 폴더의 하위 디렉터리 하나가 내용 변경 push 한 묶음이다. 하위 폴더가 없으면 대기 중인 인수인계가 없는 상태다. 이 안내 파일은 삭제하지 않는다.

- 읽는 순서: 해당 폴더의 `changes.md` → 상대의 코멘트 → 실제 변경 파일 → 본인의 코멘트·읽음 기록.
- `DRAFT`는 아직 push가 확인되지 않은 초안이고, `OPEN`은 실제 공유를 확인한 인수인계다. 날짜가 지났다는 이유만으로 완료 처리하지 않는다.
- 읽음 판정과 삭제 조건은 [협업 운영 규칙](../../guides/collaboration.md#git-handoff)을 따른다. 두 사람의 최신 확인과 원격 Git 보존을 확인하기 전에는 남겨둔다.
- 미처리 질문이 있으면 답하거나 담당 문서로 이관하고 담당자·다음 행동을 기록한다. 빈 코멘트는 `의견 없음`이 아니다.
- 이미 삭제한 건은 별도 사본을 쌓지 않고 Git 이력에서 찾는다. 삭제 뒤 다시 전달할 내용이 생기면 새 인수인계로 작성한다.
