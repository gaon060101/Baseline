# <백가온 또는 박민수>의 코멘트와 읽음 확인

- 이름: <백가온 또는 박민수>
- 코멘트 버전: 0

## 사용자 전달 코멘트

미등록. 작업 중 따로 전달하도록 지정한 내용만 아래 형식으로 순서대로 추가한다. 이 양식이나 빈 절 자체는 실제 코멘트가 아니다.

```text
### UC-001 — <짧은 제목>
- 요청일: <YYYY-MM-DD; 시각을 확인했다면 KST로 추가>
- 전달자: <백가온 또는 박민수>
- 분류: <의견 / 질문 / 제안 / 요청 / 확정 결정 / 미분류>
- 원문 출처: <사용자 발언 / 보조 도구 설명 / 자료 출처 등>

> <전달하도록 지정한 원문>
```

원문 인용과 사용자 요청에 따라 정리한 요약을 구별한다. 분류·전달 요청만으로 동의·실행 승인으로 해석하지 않는다.

## 일반 검토 코멘트

미작성. 변경사항·질문·검토 의견·다음 작업을 적는다. 의견이 없으면 `추가 의견 없음`이라고 직접 작성하고 코멘트 버전을 올린다. 다른 사람의 코멘트를 대신 채우지 않는다.

## 보조 도구 설명

없음. 원문 이해를 위한 보충이 필요하면 여기에 별도 표시한다. 사용자가 직접 한 말처럼 쓰지 않는다.

## 내 읽음 확인

- 상태: 미확인
- 읽은 내용 버전: 미확인
- 읽은 내용 커밋 C: 미확인
- 읽은 상대 코멘트 버전: 미확인
- 확인 시각: 미확인
- 확인 주체: 미확인
- 읽은 핵심 내용·다음 행동: 미작성

실제로 읽은 뒤 상태를 `확인`으로 바꾸고 나머지 항목을 채운다. 확인 주체는 `본인` 또는 `<이름>의 요청에 따른 도구 대리 열람`처럼 구분한다. 보조 도구만 읽었다면 사람이 읽었다고 적지 않는다.

사용자 전달 코멘트·일반 의견·보조 설명 등 의미 있는 본문이 바뀌면 코멘트 버전을 올린다. 버전이 이미 1 이상이면 `추가 의견 없음`을 적을 때도 기존 버전에서 올리며 1로 되돌리지 않는다. 읽음 상태·시각 등 확인란만 바꾸는 경우에는 코멘트 버전을 올리지 않는다. 읽음은 동의나 실행 허가가 아니다.
