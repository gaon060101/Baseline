# 이번 push 인수인계: <제목>

이 양식을 `collaboration/pending/<YYYYMMDD-HHMMSS-작성자-주제>/changes.md`로 복사한다. 같은 폴더에 코멘트 양식을 복사한 `백가온.md`, `박민수.md`를 만들고 해당 이름을 넣는다. 꺾쇠 자리와 미정 항목은 확인한 사실로 채운다. 템플릿 자체에 읽음 기록을 남기지 않는다.

## 식별과 공유 상태

- 인수인계 ID: <폴더명과 동일>
- 담당 작성자: <백가온 또는 박민수>
- 참여자: 백가온 / 박민수
- 대상: <칼럼 번호 또는 프로젝트 공통>
- 내용 버전: 1
- 상태: DRAFT
- 비교 기준 커밋: <변경 전 전체 SHA 또는 신규 공유임을 명시>
- 공유한 내용 커밋 C: 미정
- 공유 브랜치: <실제 대상 브랜치>
- push 확인: 미확인
- 작성 시각: <YYYY-MM-DD HH:mm KST>

`DRAFT`에서 실제 push 성공을 확인한 뒤 `OPEN`으로 바꾸고 내용 커밋 C·확인 시각을 적는다. C를 만드는 커밋 안에 C 자신의 해시를 넣지 않는다. 이미 생성된 C를 후속 기록에서 참조한다.

## 확인·정리

읽음과 의견은 같은 폴더의 `백가온.md`, `박민수.md`에서만 관리한다. 내용·검증·할 일·이관 내용이 달라지면 내용 버전을 올린다. 확인 시각·전송 증빙만 추가하는 경우 버전을 올리지 않는다. 두 사람의 최신 읽음, 질문 처리·이관, 완성본의 원격 Git 보존을 확인하기 전에는 삭제하지 않는다.
