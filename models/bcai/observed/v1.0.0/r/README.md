# BCAI-OBS-v1.0.0 R 실행 안내

이 폴더는 **투구 행에서 카운트별 관찰 BCAI를 계산하고, 시즌별·통합 지수와 연도 차이 구간, 블로그용 PNG를 저장**한다. 2024·2025에서는 기존 Python의 점추정·분모·제외 내역을 허용오차 `1e-9` 안에서 재현했다. [2024·2025 결과 보고서](../../../../../columns/001-ball-count/analysis/runs/bcai_r_check__mlb_2024_2025__20260928__r02/report.md).

계산 코드는 다른 연도도 받지만 **코드의 재사용 가능성과 해당 연도 자료의 검증 완료는 다르다.** 연도별 성공 여부는 해당 실행의 `manifest.json`과 검증 결과를 따른다. 모델 의미와 제외 기준은 [카드](../model_card.md)·[명세](../specification.yaml)를 기준으로 한다. BCAP·Ridge 계산기는 아니다.

## 파일과 산출물

| 파일 | 역할 |
| --- | --- |
| [bcai.R](bcai.R) | 입력 검증, 타석·카운트 집계, BCAI, 경기 단위 부트스트랩 함수 |
| [run.R](run.R) | 설정 읽기, 일정 대조, 기존 결과와 선택적 비교, 결과·그림·manifest 저장 |
| [test_bcai.R](test_bcai.R) | 손계산 예제, 입력 오류, 제외·반복 카운트, 연도 재사용, 난수 재현 확인 |

실행은 `columns/001-ball-count/analysis/runs/<run_id>/`에 설정·manifest·결과를, `columns/001-ball-count/figures/<run_id>/`에 그림을 둔다. 결과 CSV는 시즌별 지수, 혼합 지수, 지정 연도 차이, 유효 표본, 제외 내역, 사건 비율이다. 재표본은 `bootstrap_draws.rds`, 환경은 `sessionInfo.txt`에 저장한다.

현재 R 결과는 **주 지수·불확실성·감사 내역**에 집중한다. 기존 Python 산출물의 명목/확정 등급, 보조 득점 지수, Ridge 결과를 모두 재생성하는 완전 대체 실행기는 아니다.

## 실행 방법

[R 연결 안내](../../../../../guides/r_setup.md)에 따라 R과 `data.table`, `ggplot2`, `jsonlite`, `digest`가 필요하다. 저장소 루트에서 실행한다. 다음은 **설정 파일을 준비한 뒤** 실행하는 형식이다.

```powershell
./tools/run_r.ps1 -Script models/bcai/observed/v1.0.0/r/run.R <새_설정_JSON_경로>
```

함수의 모의 자료 확인은 다음과 같다.

```powershell
./tools/run_r.ps1 -Script models/bcai/observed/v1.0.0/r/test_bcai.R
```

완료·실패 실행을 덮어쓰지 않는다. 같은 run ID에 manifest, artifacts 또는 그림 폴더가 있으면 실행기가 중단한다. 새 ID·새 설정 파일을 만들고 기존 기록을 보존한다. 실패 후 같은 ID의 파일을 지워 재사용하지 않는다.

## 설정 JSON

[2024·2025의 실제 설정](../../../../../columns/001-ball-count/analysis/runs/bcai_r_check__mlb_2024_2025__20260928__r02/config.json)을 구조 예시로 쓴다. 그 설정의 run ID를 그대로 다시 실행할 수는 없다. 파일 경로는 저장소 루트 기준이다.

| 필드 | 내용·조건 |
| --- | --- |
| `run_id` | 미사용 ID. `bcai_<별칭>__mlb_<기간>__YYYYMMDD__rNN` 형태. 날짜는 실제 계산일 |
| `model_id`, `version` | 각각 `BCAI-OBS-v1.0.0`, `1.0.0` |
| `input_csv` | 하나 이상의 CSV 경로 배열. 설정 연도와 입력 연도가 정확히 일치해야 함 |
| `input_provenance` | 입력의 원출처·변환·해시 기록 파일 경로 배열 |
| `years` | 중복 없는 정수 연도 배열 |
| `seasons` | 각 연도에 `year`, `cutoff`(YYYY-MM-DD), `scope`, `schedule`(MLB 일정 JSON) 지정 |
| `weights` | 각 연도의 `year`, `BB`, `HBP`, `1B`, `2B`, `3B`, `HR` 양의 유한 가중치. 입력 연도와 정확히 일치 |
| `weights_source` | 실제 적용 가중치의 확인 근거를 보존한 로컬 파일 경로 |
| `reference_run` | 선택 항목. 기존 Python의 `advantage_count_results.csv`, `advantage_season_sensitivity.csv`, `advantage_audit.json`이 있는 실행 경로. 대응 기존 결과가 없으면 생략 |
| `bootstrap_replicates`, `seed` | 부트스트랩 횟수와 난수 seed. 본 분석은 2,000회 사용. 코드 최소 허용 20회는 실사용 권장 횟수가 아님 |
| `comparisons` | 예: `[[2024, 2025]]`. 뒤 연도−앞 연도 차이를 계산. 단일 연도면 `[]` |
| `tolerance` | 기존 Python 결과 비교 시 수치 허용오차. 이번 값 `1e-9` |
| `data_source`, `source_notes` | 자료 출처 설명과 로컬 출처 기록 파일 경로 |

`input_provenance`는 각 CSV의 출력 경로·SHA256을 실제 입력과 대조한다. `weights_source`, `source_notes`는 실행에서 해시를 보존하는 증거다. 출처의 이용 조건이나 가중치가 올바른지까지 내용으로 자동 판정하는 기능은 아니므로, 실행 전에 자료를 읽고 확인해야 한다. `scope`는 보고용 설명이며 실제 시즌 범위는 입력·일정·cutoff로 점검한다. 2022 이후의 새 실행부터 `artifacts/code/`에 실제 사용한 R 코드 사본도 보존한다.

## 다른 연도에 적용하기 전

1. 해당 기간 자료의 제공 범위·이용 조건을 [출처 기록](../../../../../columns/001-ball-count/sources.md)에 남긴다. 이 R 실행기는 **다운로드하지 않는다**. 입력이 없다고 임의로 수집하거나 기존 원본·정제본을 덮어쓰지 않는다.
2. CSV에 `game_pk`, `at_bat_number`, `pitch_number`, `game_year`, `game_date`, `balls`, `strikes`, `events`를 준비한다. `balls`·`strikes`는 투구 전 카운트다. 중복 투구 키·잘못된 정수·범위 밖 카운트는 오류로 중단한다.
3. 시즌별 가중치를 실제 출처와 대조한다. 다른 연도 가중치의 복사나 미확인 잠정값 사용을 피한다. 새 시즌 적용만으로 모델 버전을 바꾸지 않지만, 공식·분류·제외 기준이 바뀌면 별도 모델 변경 판단이 필요하다.
4. 저장된 일정에서 cutoff까지 종료된 정규시즌 경기 ID와 입력 경기 ID가 일치하는지 확인한다. 실행기는 누락·추가 경기와 날짜를 점검하지만, **경기 안의 모든 투구·타석이 완전한지는 보장하지 않는다**. 부분 경기·중단 경기·비정상 제외율은 별도 확인한다.
5. 새 run ID로 실행하고 `manifest.status`, 검증 결과, 사건·제외 내역, 시즌별 분모를 읽는다. 미분류 사건은 제외 감사표로 확인해야 하며 단순 완료가 자료 적합성의 자동 승인인 것은 아니다.

2024·2025 입력은 기존 Python 캐시를 CSV로 옮기는 형식 변환을 거쳤다. R 집계는 별도 구현이지만 원본 수집·캐시 전처리 전체의 독립 검증으로 표현하지 않는다. 기존 Python 결과가 없는 새 연도에서는 동일값 재현을 주장하지 않고 입력·방법·내부 일관성 확인 범위를 구별한다.

## 연도 차이와 블로그 해석

여러 시즌을 함께 넣으면 각 시즌의 0-0 평균으로 정규화한 뒤 유효 타석 비중으로 혼합한다. 비교할 연도 쌍을 `comparisons`에 미리 명시하면 **해당 실행에 지정된 모든 비기준 카운트×연도 비교 전체**에 대한 근사 동시 구간을 계산한다. 시즌별 구간과 연도 차이 구간은 별개다.

**같은 seed로 따로 실행한 연도별 재표본을 행 번호만 맞춰 빼면 안 된다.** 연도 비교는 비교 대상 자료를 한 설정으로 넣은 다년 실행에서 수행한다. 새로운 비교 쌍을 추가할 때도 새 run ID를 사용해 비교 집합과 동시 구간을 다시 남긴다.

외부 가중치·시즌 혼합비는 고정하며 경기 안의 의존성을 반영한다. 다른 경기의 같은 선수 간 의존성·가중치 추정 오차까지 반영하지 않는다. 연도 차이 구간이 0을 포함하면 차이가 확인되지 않은 것이며 동등성의 증거는 아니다. BCAI는 관찰 평균이지 승률·인과 효과·최적 행동의 점수가 아니다.

PNG는 한글 제목·축·출처·표본·해석 주의를 포함한다. 블로그 발행 전에는 최종 표시 크기로 글자와 범례를 확인하고, 실제 연도·분모·비교 방향이 본문과 맞는지 점검한다. 분석 완료와 기존 원고 수정·외부 게시를 구분한다.
