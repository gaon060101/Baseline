# BCAI-STATE-DELTA-v0.1.0

상태: **EXPERIMENTAL · 구현 및 소형 요약 산술 확인 완료, 전체 검증 미실시**.

기존 BCAI-OBS의 시즌별 원 W 상태 평균을 이용한 설명용 모듈이다. 2024·2025 각각 12카운트의 현재 V, 다음 볼/스트라이크 상태값, 현재와의 차이, 다음 두 상태 간 격차를 계산한다. 볼·스트라이크가 실제 발생한 투구 집단의 W 평균과는 다른 표다.

입력은 기존 `advantage_season_sensitivity.csv`의 `year,count,N,value`이며 `value`가 원 W다. 상대지수나 BCAP 행동값으로 대체하지 않는다. V의 분모는 유효 PA×count를 한 번만 센 도달 PA 수다. 도달률은 시즌 0-0 유효 PA 대비 비율이다. 여러 카운트에 같은 PA가 포함되므로 비율 합은 100%가 아닐 수 있다. 다음 상태 분모도 그 상태 전체 도달 PA이며 현재 카운트에서 실제로 발생한 특정 사건 수가 아니다.

3볼의 볼 분기는 시즌 BB 가중치, 2스트라이크의 일반 삼진 분기는 K=0이다. 일반 2스트라이크 파울은 자기유지로 차이 0이다. 번트·HBP·낫아웃·실책·파울팁·자동 판정의 별도 취급은 [실행 명세](specification.yaml)의 `exceptions`와 실행 보고서에 기록한다. 기존 유효 PA와 최종 사건 부호화를 유지하되 이 특수 사건을 보통 볼/스트라이크로 새로 분류하지 않는다.

서로 다른 도달 집단의 평균 차이이므로 인과 효과·투구 지시·미래 보상 예측으로 해석하지 않는다. 시즌 가중치 차이가 있어 두 연도는 별도로 제시한다. 최종 PA W에 매 공 차이를 더하지 않는다. 실제 사건 발생률·사건 조건부 최종 W·새 불확실성은 미산출이다. 기존 OBS의 상대지수 구간·VALIDATED 상태를 전용하지 않는다.

실행은 [run.py](run.py), 확인 범위는 [validation.md](validation.md), 이번 계산은 [실행 manifest](../../../../columns/001-ball-count/analysis/runs/bcai_state_delta__mlb_2024_2025__20260917__r01/manifest.json)와 [24행 보고서](../../../../columns/001-ball-count/analysis/runs/bcai_state_delta__mlb_2024_2025__20260917__r01/report.md)에 있다. 표는 새 적합 없이 저장 요약으로 계산한 관찰 산술 결과다.
