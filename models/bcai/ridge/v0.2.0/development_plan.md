# BCAI-RIDGE-v0.2.0 개발·외부 검증 사전 계획

2026-09-08 작성. 2023·2026 결과를 읽기 전의 계획이다. 추정 대상 J(카운트별 중심화 잔차 지수)를 유지하고 변수·solver·교차검증을 변경하므로 Minor 0.2.0으로 등록한다. 기존 OBS 및 Ridge v0.1.0 정의·실행은 보존한다.

## 고정할 설계

- 개발은 2024·2025만. 타자 공통 ID, 투수 공통 ID, 시즌, 구장 공통 ID, 좌우 조합, 기존 점수 구간(-∞,-4],(-4,-1],(-1,0],(0,3],(3,∞), 주자 8상태, 아웃, 이닝(10회 이상 통합)의 가산 범주 효과. 타석 시작 기록을 사용한다. 위치·추가 상호작용은 제외한다.
- 각 훈련 fold에서만 범주 사전·시즌 기준 평균 V_train을 구한다. 목적변수 z=W/V_train, 목적함수 Σ(z−a−Xβ)²+αΣβ², 절편 비벌점. 고정된 이벤트 가중치는 2024·2025 기존 OBS와 같다. 유효 PA·제외·중복 규칙도 OBS와 같다.
- 훈련 빈도로 중심화한 범주 효과를 사용한다. 신규 선수·구장·시즌 등의 블록 효과는 0(그 블록의 훈련 PA 가중 평균 효과). 미관측 여부와 과거 표본 수를 기록한다. 외부 결과로 계수 재학습 없음.
- 내부 CV 평가는 해당 훈련 fold 기준 척도의 MSE와 비벌점 상수 1을 비교한다. 원 가중치 단위 MSE도 기록한다. J 계산은 평가 시즌의 실제 V_eval로 관찰 W와 훈련 예측 W를 함께 환산하고 0-0 잔차 평균을 뺀다. 외부 V_eval은 사후 집계 기준이지 예측 입력·튜닝에 사용하지 않는다.
- 외부 미관측 시즌의 예측 W 변환에는 개발 전체의 PA 가중 평균 V_train을 고정 사용한다. 기존 시즌은 해당 훈련 시즌 V_train. 외부 MSE 주 척도는 개발 기준 고정 척도, 보조로 원 W 단위 제공. 외부 평균을 알고 예측하는 상수는 주 비교 기준으로 쓰지 않는다.
- 외부/내부 5×3 경기 단위 중첩 CV. sorted game ID를 독립 seed 20260908 기반으로 섞어 균등 fold 배정. 선수는 fold 간 공유될 수 있으나 같은 경기는 분리되지 않는다. 2024·2025 안의 경기 재현 평가이며 선수 완전 분리/시간 분할은 아니다.
- 초기 로그 α 후보 1,3,10,30,100,300,1000,3000. 사전 확장 후보 10000,30000까지 함께 확인한다. 최소 평균 내부 fold MSE로 선택하며 동률은 큰 α. 1-SE(최저 평균+해당 fold SE 이하인 가장 큰 α)도 비교만 보고한다. 최종 α는 개발 전체 별도 5fold CV의 최소 MSE. 외부 outer fold MSE로 선택하지 않는다. 최소점이 끝이면 외부 개봉 전에 개발 데이터에서만 범위 재검토한다.
- centered Gram의 Jacobi 전처리 공액경사(PCG)로 같은 Ridge 목적함수를 푼다. 실제 훈련 예측 최대 변화 <1e-7, 상대 목적함수 변화 <1e-12, 정규방정식 잔차 조건도 동시에 점검. 최대 5000회, 수렴 후 10회 추가 검증. 모든 적합의 목적함수·최대 변화·카운트별 지수 변화·진동 진단 보존. 최종 적합은 다른 초기값 및 독립 직접 선형해와 비교한다. 미수렴은 성공으로 표시하지 않는다.
- Ridge CI는 이번 버전에서 산출하지 않는다. OBS 구간/확정 등급을 Ridge에 붙이지 않으며 명목 방향·경계 비교만 한다.

## 외부 표본 봉인

2023 전체 정규시즌은 외부 재현 검증, 2026은 2026-09-07 공식 경기일까지의 완료 정규시즌 경기로 외부 시간 순방향 검증한다. 실제 가용 마지막 경기일·완료 경기 수를 명시하고 다운로드 시각과 해시를 고정한다. 진행/취소 경기는 제외한다. 2026 최종 시즌 검증은 별도 실행이다.

2023은 공식 해당 시즌 가중치를 사전 고정하고 2026은 2025 가중치를 고정한다. 2023/2026을 개발·선택에 사용하지 않는다. 최종 구조·선택 α·전처리·코드·계수 해시와 freeze 시각을 저장한 후에만 외부 원본을 확보하고 평가한다. 실제 외부 결과를 본 뒤 어떤 변경도 하지 않는다. 데이터 오류나 구현 오류로 재평가가 필요하면 원 실패 실행을 보존하고 변경·새 버전 필요성을 명시한다.

외부 데이터는 실제 출처의 제공 범위와 조건을 확인한 뒤 필요한 두 시즌만 확보한다. 접근이 불가능하면 외부 검증을 미실시로 기록하고 데이터를 만들지 않는다. KBO·Drive/Docs 작업은 하지 않는다.
