# BCAP R 실행 안내

원 경기 분할·보정 경기·선택된 규제값을 재사용해 R에서 새로 적합했다. 네 모델 모두 원 Python 행별 점수와 허용 오차 안에서 일치하고 지원 행 마스크는 정확히 같다. 가장 큰 행별 p 차이는 4.46e-8, 결과 회귀값 차이는 2.17e-9 미만, AIPW 점수 차이는 2.42e-6 미만이다. SWING의 원 Python 요약 CSV와 R delta 최대 차이는 1.35e-9다. 수치 구현 재현이며 EXPERIMENTAL 상태를 유지한다.

전체 출력 해시·입력 보존·동결 코드·원 Python 집계 대조의 사후 기록은 [통합 사후 검산](../../../columns/001-ball-count/analysis/runs/bcap_r_postflight__mlb_2024_2025__20260928__r02/README.md)에 있다. 그림은 모델별 카운트 비교 4개와 SWING 구역 비교 1개이며 직접 열어 한글·축·범례·자료 부족 표시·잘림을 확인했다.

실패 기록도 보존했다. PITCH r01은 R data.table의 동적 그룹 열 지정 문법 오류로 중단됐고 이를 수정한 r02가 완료됐다. S/B r01은 COMPLETE와 산출물 저장 뒤 프로세스에서 `object 'reproduction' not found` 오류가 발생했다. 실행 중 원 실행기 파일을 보강한 것이 후속 파싱 오류의 원인으로 추정되어, 이후 실행은 사전 고정한 실행기·엔진 사본으로 바꿨다. S/B 완료 manifest는 그대로 보존하고 별도 사후 검산에서 입력·동결 코드·전체 산출물 해시 및 원 집계와의 일치를 확인했다.

## 계산 범위

- PITCH v0.2.0: FB와 NFB의 최종 타석 공격가치 비교.
- PITCH-SB v0.1.0: 기하학적 존 안(S)과 밖(B) 비교.

추정 대상은 관찰 자료의 조건부 보정 비교다. 인과 효과·실시간 전략·PA 전체 정책 개선량 또는 행동 추천으로 해석하지 않는다.

## R에서 새로 수행하는 것

훈련 자료에서만 범주 사전을 만들고, 절편을 벌점에서 제외한 centered ridge를 Jacobi-PCG로 적합한다. 훈련 안 별도 경기의 Platt 보정을 적용하며, 행동별 결과 모형은 각 행동의 훈련 행에 적합한다. 경기 3분할 OOF 예측, AIPW 점수, 공통 지원 조건, 표본·ESS·경기 분산 조건, 고정 점수의 경기 군집 t 구간을 R에서 계산한다.

2024·2025 재현에서는 원 실행의 경기 분할 및 보정 경기 목록만 재사용한다. Python transport는 원 pickle을 CSV로 형식 변환하고 원 점수를 대조용으로 내보낼 뿐 새 추정은 수행하지 않는다. R 적합이 원 점수나 원 계수를 학습 입력으로 사용하지 않는다.

규제값은 기존 개발 선택을 고정한다: S/B는 p=m0=m1=1000, 나머지는 p=100·m0=m1=1000. S/B의 규제 선택 탐색 자체를 재현하는 작업은 아니다.

다른 연도에는 제공한 경기 분할이 없으면 R의 고정 seed로 경기 단위 분할을 생성하고 실제 목록을 저장한다. 같은 seed 숫자로 NumPy의 순열이 재현된다고 주장하지 않는다. 새 연도마다 자체 OOF 재적합하는 패턴 재현이며 개발 모형을 고정한 외부 예측 시험과 구별한다.

## 실행

프로젝트 루트에서 수치 검사를 실행한다.

```powershell
& ./tools/run_r.ps1 -Script ./models/bcap/r/test_engine.R
```

준비된 CSV transport 폴더가 있을 때 네 모듈을 순차 실행한다.

```powershell
& ./tools/run_bcap_r_models.ps1 -InputDirectory <입력폴더> -Years 2024,2025
```

새 연도 원자료를 R에서 준비한 RDS로 실행할 수도 있다.

```powershell
& ./tools/run_bcap_r_models.ps1 -InputRds <새준비본.rds> -Years 2022
```

실행기는 새 실행 ID만 사용한다. 실패한 실행도 보존하며 다음 호출은 새 번호를 사용한다. 더 큰 비교 가족을 사전에 적용할 때 `-ComparisonFamily`를 지정하고 그 이유를 실행 계획에 기록한다. 2026은 존 정의의 측정 비교 가능성을 검토하기 전 S/B·SWING 계산을 차단한다.

현재 실행기는 시작 전에 `execution_configs/<run_id>/run.R`와 `engine.R`를 함께 고정하고 그 사본을 실행한다. 실제 사용한 두 파일의 해시와 동결 사본을 결과에 저장한다. 새로운 `frozen_run.R`는 같은 폴더의 `frozen_engine.R`를 우선 읽으므로 재실행 시 현재 작업 중인 엔진과 섞이지 않는다. PITCH r02·S/B r01은 이 보호 장치 추가 전 실행으로, 그때의 `frozen_run.R`는 원 상대 경로의 엔진을 참조한다. 이 두 이전 실행을 정확히 다시 실행하려면 별도 작업 폴더에 동결 실행기·엔진을 해당 상대 경로로 배치하고 새 실행 설정을 사용해야 한다. 기존 실행 폴더에 직접 재실행하지 않는다.

## 검증과 해석

`test_engine.R`은 작은 설계행렬의 직접 해와 PCG 결과를 비교하고, 훈련에 없는 범주의 기여 0, 경기 군집 표준오차, 지원 경계·집단 조건, AIPW 관측 행동별 보정을 확인한다.

원 Python 점수가 제공된 재현은 모든 적격 행을 맞춰 p·mu 최대오차 1e-6, phi 최대오차 1e-4, 요약 통계 최대오차 1e-6를 검증한다. 지원 마스크는 정확히 같아야 한다. 실제 최대오차는 `python_score_comparison.csv`와 `python_summary_comparison.csv`에 남긴다. 이는 독립 수치 구현 검산이며 통계모형의 인과 식별 또는 실제 구간 포함률 검증이 아니다.

`action_values.csv`는 전체 기간의 원 비교 가족을 적용한 요약이다. `year_values.csv`는 같은 OOF 점수의 연도별 하위집단 요약이다. 2024·2025 `year_differences.csv`의 차이는 2025−2024이며 두 시즌의 경기 군집 분산을 합친 고정 점수 근사와 별도의 고정 255 가족 보정 구간을 제공한다. 이 연도 차이의 가족은 `-ComparisonFamily`와 별개이며, 네 모델의 해당 연도 차이 총 232개를 포함한다. 공유 학습 모형의 불확실성과 경기 간 선수 의존성은 포함하지 않는다. 여러 연도의 결과를 한꺼번에 선택하여 결론을 내릴 때 기존 연도 내부 구간을 전체 역사 비교의 보정 구간으로 부르지 않는다.

블로그 PNG는 `count_by_year.png`이며, 모바일에서 카운트와 방향·구간을 읽도록 만든 정적 그림이다. 게시 또는 기존 원고 변경은 이 실행에 포함하지 않는다.
