## 남은 결정/제약

- Ridge 수렴 기준 미달과 낮은 설명력은 그대로 남는다. 이를 개선하면 별도 설계/버전 결정이 필요하다.
- 기존 코드는 두 모델 공동 실행이며 명세 YAML을 직접 읽지 않는다. 독립 실행기/설정 로더 공통화는 이번에 하지 않았다.
- 최초 실행일은 보고서의 날짜 단위 기록이며 시각·당시 git revision·별도 원본 코드 스냅샷은 없다. migration 전 코드 SHA256을 manifest에 보존했다.
- 새로운 실행은 검사 후 manifest를 등록해야 한다. 자동 등록기·팀의 추가 승인 절차는 후속 개선 사항이다.
- KBO 기간·상수·제공 범위는 미정. Google Drive/Docs는 변경하지 않았다.
